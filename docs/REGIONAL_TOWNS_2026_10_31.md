# 地域ごとの街並み

51都市を建築10様式、屋根・外壁・舗装の配色、地域をイメージした植生、屋根飾り、北端の遠景で描き分ける。街外にも同じ地域の植生と水辺の色調を適用する。高精細素材に陰影や格子・欄干・瓦目・屋根飾りを重ね、静的キャッシュへ描画する。追加の素材通信や毎フレームの再生成は行わない。

実在都市の建物や地図を忠実に再現するものではなく、地域の特徴から着想した創作RPGの街並み。同県の都市も個別設定で区別する。配置バージョン3、通行判定、店・NPC・宝箱・港・出入口の位置、報酬、依頼、保存キー、保存位置は変更しない。

公開main d2bf60fとの比較では、外観メタデータを除く全MAP・HUBS・QUESTS・AREASのJSONが一致した（SHA-256: e2b8f9ce473ba39cdeca636293fd40bc2b6af9a7f2ff570385a102bb51f81763）。

検証は node scripts/check-regional-art.mjs（同一配置で51種類の実描画差、10建築様式、32MiBキャッシュ上限、データ不変）、node scripts/test-regional-towns.mjs（19都市、4モバイル模擬画面サイズ）、既存の全回帰検査。実スマートフォンでの検査とは区別する。
