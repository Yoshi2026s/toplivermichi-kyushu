# 全国MAPの歩行経路・再開操作の改善

全国図とミニMAPに実際の残り歩行経路を表示。曲がり角を保った折れ線にし、停止中は点線、街名は経路より上に描く。目的地の欄に残り歩数と再開・取り消し操作を用意する。地図を開くと歩行配列が消えるため、停止時は通行可能な経路を再計算し、同じ位置・予定・解放状態では再利用する。保存・位置・歩行速度は変更しない。

街道曲の打楽器と終盤の効果を55%にし、高音アクセントも抑える。港曲や他地域の曲は維持。

## 検証

- test-world-walking-route.mjs：4サイズで停止中の経路再構築、残り歩数、全区間の通行可能性、折れ線圧縮・計算結果の再利用、48px操作、再開・取り消し、閲覧専用、古い操作の無効化を確認。
- test-world-audio.mjs：街道・港の全編PCMと既存曲を検査し、街道の終盤まで打楽器の強さを確認。
- 既存の全国MAP表示・検索・解放制限・連続歩行・船移動・保存復元、72件の回帰検査と生成物照合を実施。
- 統合後は公開ファイル21件の一致と公開URLのMAP操作・ブラウザー再起動／バックアップ復元を確認する。

スマホ検証はブラウザー模擬。実機スマートフォン・イヤホンでの聴感確認は含まない。
