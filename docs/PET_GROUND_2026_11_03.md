# 同行ペットの足元の修正

MAP上のペットは96×112の画像の下端を地面に合わせていたため、透明な余白の分だけ足先が影から浮いて見えていた。
各種類・成長段階・方向・歩行フレームの画像を生成した際に、不透明な描画の下端を調べてキャッシュし、その位置を影の中心へ合わせる。
画像の大きさ、同行経路、保存形式、能力計算は変更しない。既存の64枚上限のキャッシュを使い、毎描画で画素を読み取らない。

- `check-pet-ground.mjs`: 22種類×成長4段階×4方向×停止および8歩行フレーム、計3,168件。実際のMAP描画式で接地とキャッシュ上限を検査。
- `test-pet-ground.mjs`: 6画面サイズで2匹同行・4方向の接地、横はみ出し、ページエラーを確認。CIでも実行。
- 既存のペット検査と4サイズの施設・移動・保存後の再読込も実行。

スマートフォンの確認はブラウザー模擬検証。実機スマートフォンは未確認。
