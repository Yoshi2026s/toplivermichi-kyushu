# 音・表示・操作の改善 第4回（2026-11-01）

PR #63の公開版を基点に、ノイズ音の音量変化と通知の保持、戦闘操作の表記を改善する。

- BGMの打楽器やノイズ系効果音は、ほぼ無音から最大3msで立ち上げ、終端もほぼ無音まで減衰させる。最初から大きな音量で始まる処理を置き換え、短い打楽器の反応と再生時間を維持する。
- 通知は画面の再描画対象から分離した1個の要素で表示する。メニューや戦闘画面の再描画で通知が消えたり、古い要素だけを終了タイマーで隠したりする問題を防ぐ。既存の表示時間・文字列の安全な表示・操作を遮らない設定を維持する。
- 戦闘中央のオート中断ボタンを「手動に戻す」へ変更し、ドックと表示・読み上げをそろえる。中央とドックの両方から手動へ戻れることを確認する。

曲・素材・保存キーや形式、戦闘の計算・報酬・移動の仕様は変更しない。追加の外部依存はない。

## 検証方法

- 修正前にノイズの立ち上がりと通知の再描画保持の検査を実行し、失敗を確認する。
- ノイズの短い立ち上がり・静かな終端・音源数制限を検査し、タイトル・地上・戦闘のステレオ波形で有限値・最大振幅・消音・復帰も確認する。
- 通知は4サイズで再描画・画面切替後の保持、要素が増えないこと、HTML文字列の安全な表示、操作を遮らないこと、表示終了後に復活しないことを確認する。
- 戦闘とメニューは6サイズで検査し、中央・ドックのラベル一致と両方からの手動復帰を確認する。

ブラウザー模擬と波形の自動検査による確認であり、実際の試聴・物理スマホ・イヤホンでの音質とは区別する。利用者の既存保存データは使わない。

- 6サイズで中央とドックの表記・読み上げの一致と、両方からの手動復帰を確認。小画面の通知・オート戦闘の保存画像を目視確認。
