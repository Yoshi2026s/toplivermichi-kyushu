# ポコチャクエスト｜トップライバーへの道 九州編

**公開版：v5.29（2026年10月22日の確認済みZIPから再配置）**

ドラフトPRのプレビューは v5.29-dev。福岡編に加え、佐賀県唐津市のM03・佐賀市のM04、長崎県佐世保市のM05・長崎市のM06まで、各3探索区域・地域ボス・配信を実装中です。M06完了後は熊本市の休憩拠点に移動できます。佐世保市編以降の内容は移行作業で新規作成したもので、参照版との一致は未確認です。

男女混合アイドルグループを脱退したヒロインと旅立ち、九州・沖縄で仲間を集めてトップライバーを目指す、スマートフォン向けの創作RPGです。公開中の版は**第1章 福岡（福岡市・北九州市、M01・M02と初配信まで）**です。ドラフトPRでは長崎市編M06までを実装中です。
