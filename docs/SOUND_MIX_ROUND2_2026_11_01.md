# 音・表示・操作の改善 第2回（2026-11-01）

PR #61の公開版を基点に、音量調整と残響の混ざり方、設定の配置を改善する。

- BGM・効果音の音量変更は25msでなめらかに反映し、値を瞬時に切り替える処理を置き換える。変更途中に再調整しても、現在の音量から次の値へつなぐ。
- 重要な効果音の際はBGM本体とリバーブ・ディレイの戻りを同じ比率・時間で下げ、同時に元へ戻す。残響だけが大きく残る状態を避ける。
- 効果音でBGMを下げている途中に音量0へ変えても、BGM本体と残響を0へ揃える。ミュート・非表示の音源解放と、前回の連打抑制を維持する。
- BGM・効果音の音量設定を「音と演出」の中へ移動。保存・復元・共有の欄より前に置き、関連する操作をまとめる。音量枠のスクロール余白を確保する。

曲・素材・音量の保存値・保存キーや形式、戦闘・報酬・移動の仕様は変更しない。追加の外部依存はない。

## 検証方法

- 音量と残響の回帰検査を修正前に実行し、音量がなめらかに変わらない点で失敗することを確認。修正後はBGM本体・残響・こだまの同時減衰と復帰、途中の消音、旧ブラウザー向けの代替処理を検査する。
- 実ブラウザーのOfflineAudioContextでタイトル・地上・戦闘の各5秒を実際の音源から描画する。途中の音量変更、効果音、全音量0、再開を含め、有限の波形、最大振幅1未満、消音区間の無音、復帰後の波形、音源解放を確認する。WAVを検証用フォルダーへ出力する。
- 音量設定5サイズで操作・フォーカス・48px寸法・横溢れ・保存復元欄より前の配置を確認し、タイトルBGMと全体回帰も行う。

ブラウザー模擬・音声波形の検査であり、実際の試聴や物理スマホ・イヤホンの音質確認とは区別する。利用者の既存保存データは使わない。
