# 動作の滑らかさと描画負荷の改善（2026-11-01）

## 対応

- ミニマップは地形をMAPごとにキャッシュし、現在地・カメラ・表示範囲が変わった時だけ更新する。描画ごとのcanvasサイズ再設定と全タイルの塗り直しを廃止。MAPオブジェクトが変われば別の地形を作る。
- 景色の揺れや待機中の動きは、約6回/秒の間引きから上限30回/秒へ。歩行の補間は従来どおり画面更新に同期し、移動速度・到着処理・遭遇抽選は変えない。メニュー表示中は背景MAPを描画せず、動きを抑える設定は静止を維持する。
- 現在地の案内と目標が同じ時はDOMを置き換えない。移動途中の不要な要素再生成を減らす。
- 戦闘背景と敵画像は、同じアニメーションコマなら再描画しない。撃破や点滅切替は更新する。メニュー・会話・非表示タブでは定期敵描画を省く。
- 画面サイズ変更で歩行経路を空にしていた処理を削除。再レイアウトしても経路・補間位置・到着後の対象を保持する。指やキーを離した時、画面切替やアプリ切替時の既存入力解除は維持する。

保存キー・保存形式、戦闘計算、報酬、移動速度は変更しない。表示用のキャッシュはDOM/WeakMapに置き、セーブへ混入させない。

## 検証

`check-smooth-runtime.mjs` はミニマップの変更なし60回で画素処理・サイズ再設定ゼロ、移動/カメラ/MAP切替による更新、敵のコマ再利用と撃破消去、30Hzの景色更新、動き抑制とメニュー中の静止を検査する。既存のMAPループ検査も実行する。

`test-smooth-runtime.mjs` は4サイズのブラウザー模擬で画素一致、変更なし100回のサイズ再設定ゼロ、現在地案内20回のDOM変更ゼロ、経路途中のサイズ変更、各5メニュー往復、敵画像再利用と撃破消去を検査する。処理時間は参考測定として記録し、端末性能に依存するFPSの保証には使わない。検証用データと新規ブラウザーコンテキストを使用し、実利用者のセーブは触らない。

物理スマホでの体感・OSキーボードは未確認。ブラウザー模擬の結果を実機と区別する。
