# 行動・対象の選択とメニュー順序

戦闘の選択肢を「使う道具」「技の使い方」「コメントの台詞」「特殊行動」と、対象の敵・仲間・復帰させる仲間に分ける。見出しと枠で選択の段階を見分けられ、fieldset / legendで読み上げにも名前を渡す。48px以上の選択肢と選択状態、対象のHP・MP、確定前の効果の表示を保つ。長い名前は折り返し、狭い画面でも確定操作を確認できるよう既存のスクロール処理を利用する。

全メニュー上部のDOM順を見た目の左から右の順に合わせる。街・街外の「MAPへ」は左、「戻る」は右を保ち、Tab・Shift+Tabの順と画面上の並びが一致する。戦闘・結果の「戻る」も従来の位置と動作を保つ。

保存キー・保存形式・移動経路・戦闘計算は変更しない。選ぶだけでターン・道具・体力を消費しない。

## 検証

- `test-command-groups.mjs`：攻撃・コメント・回復道具・復帰道具・技のモード・特殊行動の6種類を6画面条件で確認。選択欄の名前、対象との分離、選択状態、表示幅、48px操作領域、確定位置、状態の非消費を検査する。4画面から開くメニュー上部の並びと戻る操作も確認する。
- `test-focus-visibility.mjs`：全36メニュー×6条件で上部のDOM順と見た目の順を照合し、正逆Tab循環・選択の可視性を検査する。
- メニュー往復、全メニュー配置、戦闘と結果、移動の既存検査と72項目の回帰検査、生成物の照合を実施する。
- 統合後、公開21ファイルの一致と公開URLでの主要操作を検証する。

ブラウザーで標準・小画面・横向き・低い高さ・幅320px・入力時相当の高さを模擬する。実機スマートフォン・実際のOSキーボード・読み上げ機器は未検証。
