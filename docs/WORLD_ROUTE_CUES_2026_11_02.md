# 全国MAPの行先表示・音楽の追加改善

街名検索、解放状況の絞り込み、現在地域の優先表示を追加。全国図・ミニMAPに港と移動先を示し、移動先の表示ボタンを用意する。現在地と目的地の印は街名を覆いにくい輪郭にし、街名を枠の上段へ置く。検索と表示は閲覧専用でも利用でき、保存・進行・歩行速度を変更しない。無効な行先・別の記録・取り消した予定は表示しない。

港の曲は打楽器と強い盛り上げを除き、高音のアクセントも抑える。通常の地域の曲は維持する。復元直後に現在地の曲を選び、戦闘中の復元・再開は陸上・ボス・海上で適切な曲にする。

## 検証

- test-world-route-cues.mjs: 4サイズで検索・Enter送信・解除・絞り込み・現在地域・港・移動先の印・表示移動・閲覧専用の状態非変更・古い予定・入力文字の安全性・48px操作を確認。
- test-world-save.mjs: 再読込・ブラウザー再起動・バックアップ復元、復元直後の曲、戦闘バックアップ、海上戦闘の再開曲を確認。
- test-world-audio.mjs: 街道・港の全編と既存曲のPCMを検査し、港の終盤を含め打楽器が発音していないことを記録。
- 最後に全51拠点の陸路・船路・通行制限、全51本編、保存互換、スマホ操作と公開ファイルの一致を確認する。

ブラウザー模擬検証であり、実機スマートフォンやイヤホンでの聴感確認は含まない。
