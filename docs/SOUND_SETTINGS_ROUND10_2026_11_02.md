# 効果音の音量差と設定画面の連続操作（2026-11-02）

前回公開main 141867eを基点に、29種類の効果音を測定して14種類の音色・音量バランスを調整した。

## 音の改善

- 被ダメージ・戦闘不能・メーター・技能・全体攻撃・斬撃・撃破・遭遇の8種類は、強いパルス倍音を三角波へ置き換え、音量と高音域を抑えた。BGMの旋律を覆いにくくし、ノイズの打撃成分と音程・長さは維持。
- 勝利・ランクはトランペット、成長・救助・きらめきはグロッケン、敗北はチェロへ変更。操作・足音・回復・購入・ペット等の既存音量は維持。音源が利用できない場合の合成音への切替も維持。
- 変更前の被ダメージは50ms窓の最大RMS約0.240、変更後の測定約0.118。戦闘8種類の最大RMSは0.14未満、29種類すべてで左右のクリッピング・非数・停止後の残音を検査する。これはWeb Audioで生成した試験波形の比較であり、実機の音圧や聴感の測定ではない。
- BGMの曲・音源・テンポ、ゲーム計算、保存形式とキーは変更しない。

## 表示・操作の改善

- 復元欄へ貼り付けた文字列が音量等の変更で消える問題を再現し修正。設定内の再描画で入力・選択範囲・入力欄とシートのスクロール・操作中のボタン・開いた操作説明を保持。
- 入力値はDOM上で引き継ぎ、保存データやブラウザーの永続領域には保管しない。設定を閉じた場合は未送信の復元入力を破棄し、再度開いた画面へ残さない。
- 演出を減らす設定と応援コメント設定に選択状態の読み上げを追加。応援コメントの選択色もほかの設定へ合わせる。

## 検証

- 修正前は設定の再描画で貼り付け内容が消える検査が失敗。修正後は標準・小画面・横持ち・低い高さ・320px幅・キーボード相当の高さの6サイズで確認。
- 全29効果音を録音音源あり・合成音への切替の計58条件で検証。既存のタイトル・探索・戦闘のステレオ波形、音量・消音・復帰・場面切替も確認。
- 必須CIへ効果音の全数検査と設定の連続操作検査を追加。全体回帰、隔離配布候補、CI、公開ファイル照合と公開画面確認の結果は公開記録へ記載。

端末画面はブラウザー模擬。物理スマホ・スピーカー・イヤホンでの聴感確認は未実施。復元操作の送信は行わず、専用の検証ブラウザーのみを使用する。
