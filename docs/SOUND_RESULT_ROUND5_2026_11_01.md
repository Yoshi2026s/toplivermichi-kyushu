# 音・結果画面の改善 第5回（2026-11-01）

PR #64の公開版を基点に、BGMの場面切替と結果画面の読みやすさを改善する。

- 場面切替で再生中の音源は12msで音量を下げ、20ms後に停止する。まだ鳴っていない予約音は直ちに取り消す。すでに減衰中の音は減衰を延長せず、切替を繰り返しても古い音が残り続けないようにする。
- 効果音はBGM切替の停止対象から除外する。消音・非表示は従来どおり全音源を直ちに解放する。減衰中の音源も既存の音源数上限に含める。
- 同じ戦闘結果の再描画や設定などからの復帰では、結果のスクロール位置と詳細欄の開閉状態を保持する。新しい結果では先頭へ戻り、MAPへ戻るボタンへフォーカスする従来の挙動を維持する。

曲・素材・保存キーや形式、戦闘の計算・報酬・移動の仕様は変更しない。音源の減衰管理と結果の閲覧位置は実行中だけの情報として扱い、保存データへ追加しない。

## 検証方法

- 修正前に、再生中のBGMが急停止する検査と結果の閲覧位置を失うブラウザー検査の失敗を確認する。
- 再生中・予約中・効果音の区別、短い減衰、繰り返し切替、消音と解放を検査する。既存の25場面・音源数上限・復帰検査も維持する。
- ステレオ波形は各5秒の途中でタイトル→地上、地上→戦闘、戦闘→タイトルへ切り替え、音量変更・消音・復帰・有限値・振幅を確認する。長いノイズ音の検査も維持する。
- 4サイズで結果の閲覧位置・開いた詳細・設定からの復帰と再描画、結果データが変わらないこと、新しい結果で先頭とフォーカスが初期化されることを確認する。

ブラウザー模擬と波形の自動検査であり、実際の試聴・物理スマホ・イヤホンでの音質確認とは区別する。利用者の既存保存データは使わない。
