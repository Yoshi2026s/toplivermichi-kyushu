# 全画面とメニューの選択位置の視認性

閉じた詳細欄の内容にレイアウト上の寸法が残るブラウザーでも、その内容をスティック・方向キー・メニューのTab循環の候補に含めない。詳細の見出し自体は操作でき、開けば内容にも移動できる。非表示・無効な項目は除く。

Tab・Shift+Tabと方向キーで選んだ項目を、メニューの固定ヘッダーと下端の間に表示する。街・街外・戦闘・戦闘結果では固定された下部操作部も考慮する。メニューから戻った際のスクロール復元はそのまま保ち、フォーカスを復元しただけで自動スクロールしない。Tabで選択を変えた際は中央ボタンの説明を現在の選択に合わせる。

長いメニューのスクロールが背景へ伝わらないようにし、対応ブラウザーでは背景と区別できるスクロールバー色を使う。保存キー・保存形式、移動速度・経路・戦闘計算は変更しない。

- メニュー往復、全36メニューのレイアウト、入力検索、結果の読書位置、移動・戦闘操作の既存検査と72回帰検査、生成物照合を実施する。
