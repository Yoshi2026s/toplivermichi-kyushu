# 音色・試聴・読みやすさの改善（2026-11-02）

公開mainの915bb90を基点に、録音効果音・ジングルの音色指定と設定の使いやすさを改善。

- 録音楽器にも指定されたローパスフィルターを適用。回復・購入・ペット等で高音域の抑制が無視されていた経路を修正。BGMのフィルター未指定音は従来どおり。音源・曲・音量の保存キーと形式は変更しない。
- 設定に「効果音を試す」を追加。現在の効果音音量で短い回復音を再生し、連打抑制は既存機構を利用。全体OFF・効果音0・背景・閲覧専用では鳴らさず、試聴で設定や進行を変更しない。全体OFFと個別消音の違いを説明。
- 無効なボタンの文字・背景・枠を専用色にして読みやすくし、入力欄と折りたたみ項目のキーボードフォーカスを統一。

## 検証

- 実Web AudioのOfflineAudioContextで7kHzの既知試験信号を録音音声経路へ通し、3kHz指定で左右RMSが未指定の15％未満になること、解放後に無音となることを確認。実際の音源全体の音量を15％へ下げるという意味ではない。
- タイトル・探索・戦闘のステレオ波形でクリッピング・非数・消音・音量復帰・場面変更と停止時の解放を確認。
- 5サイズで音量操作・試聴・消音時の試聴停止・案内・48px操作・横あふれ・入力欄と折りたたみのフォーカスを検証。
- 全体回帰・生成物照合と必須CIの結果、公開SHAと配信照合は公開確認記録へ追記する。

スマホの画面検査はブラウザー模擬。物理スマホ・スピーカー・イヤホンでの試聴は未実施。専用ブラウザーの検証データを使い、利用者の保存データには触れない。
