# 全国MAPの追加改善

- 全国図・ミニMAPの直線を実際の街道の折れ曲がりへ修正。全国図は1・2・4倍表示と現在地・東西南北への表示移動に対応。全操作は48px以上、閲覧専用でも使用でき、表示を変えてもスクロール位置を保つ。現在地マーカーは、街では実際の街外入口、街外では現在のタイル中央と一致させる。
- 表示範囲だけに海岸の浅瀬・輪郭、街道の細部、次の256歩までの移動予定線を描画する。全世界の画像を生成せず、地形・衝突・移動速度・遭遇規則は維持する。
- 街道は104BPM、港は88BPMの専用編曲。既存の地形曲に加え、木管・弦・ハープを中心に抑えた音量で演奏する。3歩連続で地形が変わるまで切替を待ち、停止中の再描画では判定を進めない。到着地へ大きく移動した場合は即座に切り替える。
- 海上のタップを未解放地域と混同しない短い案内へ修正。範囲外・海・未解放地域で既存の移動予定やセーブを変更しない。港オブジェクトは実際のMAP上の対象との一致も検査する。

## 検証

最後に全51拠点の陸路・船路・通行制限、全51本編、スマホ表示、旧セーブ、再読込・ブラウザー再起動・バックアップ復元と戦闘再開を再検査する。実機スマートフォンとイヤホンの聴感評価は含まない。
