# 装備とペットの一覧操作改善

### 装備・ペットの一覧検索と比較導線

手動装備は名前・ID・効果の検索と、手元から装備できる品／職業条件に合う品／すべての絞り込みを追加。装備中を先に、残りは未装備の在庫がある品から表示し、1ページ6件にする。全角英数字と複数語の検索に対応し、仲間・部位の切替、比較の取消、装備確定後も検索と絞り込みを保持する。自動セットの確定後も元の装備一覧条件を引き継ぐ。同じ装備を付けたまま他の仲間から取り上げる無効な選択肢と、何も装備していない部位を外す比較は無効表示にする。

ペットのお迎えは種名・呼び名・技名・レア度（★5など）で検索できる。確認の取消後も検索と絞り込みを保ち、クリアは両方を戻す。装備・ペットとも未送信の入力を絞り込み時に保持し、検索は保存データを変えず、閲覧専用でも使える。保存中や別画面からの古い検索操作は拒否する。

装備セットの比較画面に、能力比較・確定と取消の欄へ移動するボタンを追加する。移動操作だけでは購入・装備を実行しない。

## 検証

関連モデル、全角検索・所有者条件・技名検索を先行検査し、6画面サイズでページ送り、未送信入力、比較往復、確定後の条件保持、取消、閲覧専用、再読込と48px操作を確認する。既存のペット総合・一括購入・旧データ移行等も再検査し、全回帰・生成物照合・最新PR CIを通す。公開後はファイル一致と主要操作を再確認する。実機スマートフォンとOSキーボードは未確認。
