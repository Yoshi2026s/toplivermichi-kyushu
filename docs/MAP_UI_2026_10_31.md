# 街・街外マップと操作部の更新

- 店舗看板をカラフルにし、わくわく道具店・ほっと宿屋・おしごと広場の表示に変更。
- 各地の案内板オブジェクトを撤去。探索区域・依頼・保存形式・URLは維持。
- 陸上街外は数字の探索区域以外の歩行可能マスにも、最寄り区域の敵を割り当てる。草地などは1歩1/24、街道（w・カンマ・橋）は1/28。海の遭遇設定は維持。街・室内・歩行可能な出入口では抽選しない。
- ボス入口を塔・旗・門・松明付きの砦として描画。進入判定は従来の1マス。
- 左上に全体ミニマップを追加。白丸が現在地、白枠が表示範囲、赤がボス、黄色が出入口。
- 下部は「やる事リスト／オート移動」「メニュー／設定・保存」の2列。「戻る」を右側のジョイスティック直前へ配置。
- 矢印・ゲームパッドによるメニュー選択も下部のボタンを対象にする。

検証: check-field-encounters.mjs は全国51フィールドの草地・街道の到着で実際に戦闘開始することと、確率・安全地帯・案内板撤去を検査。test-map-ui.mjs は4サイズのタッチ模擬ブラウザーで48px以上・画面内の配置・オート移動画面と戻る・街とボス入口を検査する。実スマートフォンの確認は未実施。
