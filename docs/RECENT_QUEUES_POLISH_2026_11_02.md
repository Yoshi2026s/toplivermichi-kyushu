# 装備・ペット・能力表示の追加改善

### 直近更新の追加改善と検査

装備セットの比較画面で、最強／おすすめと仲間を切り替えても履歴を増やさず、所持品・所持金を変更しない。変更する部位と購入数・金額を先に表示する。最大HP・MPが下がって現在値を失う場合は確定前に具体的な数値と注意を表示する。手動の装備比較もセットと共通の12項目を表示し、装備中の品・職業条件外の品を明示する。次レベルの成長欄には最大HP・MPの変化も表示する。

ペットのお迎えは、今お迎えできる子・未加入・すべての絞り込みを追加し、お迎え可能な子を先に並べる。料金と残金を確認し、確定または取消を選ぶ。状態・物語条件が変わった確認画面からの購入は拒否し、保存失敗時はゴールドと所有状態を復元する。同行の組合せは自動変更しない。

## 検証方針

1. 関連モデル・移行・被ダメージ・成長を先行検査。120条件×2方式の装備提案を全組合せと照合する。
2. 6画面サイズで切替・比較・減少警告・お迎え確認・取消・保存失敗・古い操作・閲覧専用・再読込を検査し、既存の装備／通貨移行と全メニューも確認する。全回帰・ビルド・PR CIを通す。
3. 公開ファイルの一致を照合し、公開ページで主要操作を再検査する。

利用者の保存データを使わず、独立したブラウザー環境で検証する。物理スマートフォンとOSキーボードは未確認。
