# 全国MAPの経路全体・境界BGM・移動案内

地図内の「経路全体」で、残り経路と目的地が収まる1・2・4倍の最大倍率を選び中心を合わせる。操作欄は2列にして48px以上の操作面積を保つ。閲覧専用でも表示操作だけ行え、位置・記録・進行を変えない。

地域曲の最初の切り替えは既存の連続3歩。直前の曲へ戻る場合だけ、切り替え後6秒以内の往復で曲が再開しないよう抑える。待ち時間後に歩けば切り替わり、静止だけで判定は進まない。船到着・復元などの位置変更は即座に適切な曲を選ぶ。音量や楽曲自体、保存形式、歩行速度は変更しない。

船を使う徒歩案内の見出しに最終目的地と先に向かう港を併記。街内の全国行先選択はまず街外へ出る段階であることを案内し、経路が見つからない場合は説明する。
