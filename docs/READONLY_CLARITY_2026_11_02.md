# 閲覧専用の操作と説明を統一

戦闘・結果で既に行っている変更操作の無効化を共通処理にまとめ、街・街外から開く全メニューにも適用する。既存の操作許可一覧をそのまま使い、許可を増減させない。変更できないボタンは無効な見た目にし、閲覧専用の説明を関連付ける。既存の効果などの説明は残す。

各メニュー、街・街外の保存状態、戦闘のコマンド、結果の戻る操作の近くに「閲覧専用：この画面では記録を変更できません。操作中のタブで続けてください。」と表示する。検索・絞り込み・詳細確認・メニュー開閉など、既に許可されている閲覧操作は維持する。後半に描画する案内HUDにも同じ表示制限を適用し、説明は重複させない。

閲覧専用の画面本体では、実行できない戻る操作を操作パッド上でも無効にする。探索の中央ボタンは閲覧項目を選ぶ案内にする。戦闘・結果で無効な中央ボタンは、赤い決定色から無効状態の色へそろえる。通常状態で再描画すれば、説明と無効化は残らず、既存の操作が復帰する。保存キー・形式、権限判定、移動経路・戦闘計算は変更しない。
