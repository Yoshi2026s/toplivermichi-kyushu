# ステータス比較と回復準備

### ステータス比較一覧と回復の準備

カードと比較一覧を切り替え、13種類の比較軸で高い順・低い順・名簿順に並べられる。戦闘不能とHP・MPの不足割合を重視する回復優先も選択でき、同値は名簿順を保つ。比較一覧は名前・現在HP／MP・選んだ能力を小画面に収め、名前からカードへ移動できる。表示・並び順も装備や技との往復後に保持する。絞り込みや一覧切替で隠れた仲間の詳細の開閉状態を失わない。

仲間のカードから、手元にある道具のうちその仲間に効果がある回復・蘇生候補を確認できる。実際の回復処理を複製データで実行し、HP・MPの変更前後と全員回復の対象を表示する。レア度とイベント品を明示し、イベント品は後ろに表示する。確認だけでは消費せず、1個の使用を明示的に確定し、保存できた場合だけ反映する。保存失敗時は現在値・在庫・進行を復元し、古い確認・二重操作・閲覧専用での消費を防ぐ。街外でも従来どおり使用でき、戦闘中は使用できない。道具の効果・価格・保存形式は維持する。

## 検証

13比較軸の順序・同値・絞り込みと、通常道具100種とペット用品264種×HP不足／MP不足／戦闘不能／満タンの1,456ケースで、非破壊プレビューと実際の効果を照合する。6画面サイズで比較・ネイティブ選択・詳細の保持・街外回復・蘇生・全員回復・取消・保存失敗・古い確認・二重消費防止・閲覧専用・再読込を確認する。前回ステータス、既存道具、装備、全メニューの関連検査、全回帰、最新CIと公開後の一致／操作確認も実施する。実機スマートフォンとOSキーボードは未確認。

## 統合前の確認結果

全回帰81件、ビルド・生成物照合が成功。新機能と既存ステータス・装備・購入・通貨・被ダメージ・ペット表示、38メニューの閲覧専用・フォーカス・戻り操作、および画面表示をブラウザー模擬環境で確認した（8系列×6サイズ＋画面表示4サイズ、計52フロー）。新機能では保存失敗時の完全復元、街外回復、全員回復、蘇生、古い確認と二重操作の拒否、再読込を確認した。並行検査中に既存起動画面の待機が1回タイムアウトしたため負荷を減らして再実行し、6サイズすべて成功した。実機・OSキーボードの確認は含まない。
