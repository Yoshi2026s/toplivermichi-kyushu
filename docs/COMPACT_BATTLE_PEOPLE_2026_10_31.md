# 下向き・NPC統一とコンパクト戦闘（2026-10-31）

公開中main `35f5bbffc9cec871f49667fb7ae5d63a9bc01a18` を基準に、今回の表示修正だけを隔離した作業コピーで反映する。

- 下移動時は、顔・両目・鼻・体が正面を向いた専用素材 `party-down.webp` を使用する。メニュー等の立ち絵は既存素材を維持し、上下左右と歩行の対応を分ける。
- NPCは `npc-front.webp` のセミリアル調へ統一。主要6人と宿屋、地域案内人の静止表示に使用する。地域案内人は共通モデルを再利用し、名前・会話・役割・イベントは変更しない。
- パーティーとNPCは同じ64×96キャンバス、身長88、足元93の基準で描画し、MAPでも同じ16×24の大きさで配置する。NPCが歩き続ける表示は抑止する。座標・当たり判定・保存識別子は変えない。
- 戦闘は敵の絵を体力欄の横に配置し、仲間の立ち絵・余白・補助表示を縮小。職業の詳細の常時表示を省き、地域支援は補助欄へ移す。背景・体力数値・状態・主要コマンドは維持する。
- 戦闘中のドックを64pxへ縮小し、中央決定と主要コマンドのタッチ領域48pxを保つ。通常縦持ち393×851と小画面360×640では敵・仲間の体力、主要コマンド、攻撃対象選択後の確定ボタンまでスクロールなしで確認する。
- 横持ちや高さ500px以下では、長い予告・道具一覧・技説明等に応じてスクロールを許容する。敵・仲間の情報をコマンドより上に保ち、内容を切り捨てない。

画像生成スキルで既存パーティーを参考に正面素材・NPC素材を生成し、透明なセル間隔と正面の顔を目視確認した。元の生成画像を保ち、アトラスの透明境界を検出して各人物の切出し座標を記録した。配信用はWebP化してHTMLへ埋め込む。

## 検証

- `scripts/check-semireal-art.mjs`：11人分の性別差・4方向・歩行、全NPCと宿屋56表示の描画・体格・足元・静止・フォールバック非使用、キャッシュ制限。
- `scripts/check-walk-animation.mjs`：全方向8フレーム、左右鏡像、歩行と移動距離の同期、静止・画面非表示・メニューでの停止。
- `npm run test:battle-ui`：Chromeのタッチ模擬4サイズ。通常縦持ちと小画面で敵・仲間・主要コマンドが画面内か、選択後の確定ボタンがドックと重ならないかを座標で検査。長い名前・低体力・コメント・オート中断・結果画面・横はみ出し・JavaScript例外も確認。
- ビルド・全回帰・生成物一致を公開前に確認し、PRの最新CI成功後にsquashマージする。公開後はPages成功、HTMLとマニフェストのSHA-256一致、公開URLでのMAP・戦闘・保存再開を確認する。

独立した検査用ブラウザーを使い、利用者の既存セーブには触れない。PC上のChromeの画面・タッチ模擬検証であり、物理スマートフォンの実機検証ではない。
