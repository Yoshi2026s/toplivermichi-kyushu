# スマホ画面の視認性改善（2026-10-31）

- リスナーコメントは同時に1件だけを戦闘・結果画面末尾の専用欄へ表示。固定の吹き出しで敵・体力・報酬を覆わない。MAPでは表示を抑止し、保存済みのコメント設定と履歴形式は維持。
- 正面絵の左右反転を廃止し、既存の正面素材を参考に生成した横向きアトラス `assets/semireal/party-side.webp` を追加。左向きプロフィールを右方向では反転し、停止中と8段階歩行の双方で使用。上下は既存の正面・背面素材を使用。座標・当たり判定・保存形式は変更しない。
- 戦闘の敵情報に濃い背景を追加。仲間の名前・状態・体力を別行に分け、名前が状態表示で押しつぶされないように変更。
- 行動プレビューと確定操作を分離。行動・対象ボタンは48px以上にし、低い画面ではスクロールで操作できる。
- 戦闘記録とバッジは折りたたみ。使用可能な追加技が0件の無効ボタンと常時表示の補足文を省略。オート説明を短縮し、中断ボタンを維持。
