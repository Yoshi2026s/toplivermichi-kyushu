# 音声時間・タイトル選択表示の改善 第7回（2026-11-01）

PR #66の公開版を基点に、ジングルの終了判定とタイトルの選択表示を改善する。

- 勝利・レベルアップ・全滅のジングルは、AudioContextの再生時刻で終了を判断する。音声が中断され実時間だけが進んでも、途中で次のBGMへ切り替えない。残りの再生時間だけ再確認する。
- 終了コールバックは現在のジングルに属する場合だけ処理する。曲の変更・消音・非表示・ジングルの置換後に古い処理が次のBGMを開始することを防ぐ。
- タイトルボタンのスクロール余白に下部操作盤と安全領域の高さを含める。スティックやキーで選択する際に使うnearestスクロールで、音楽・設定ボタンが操作盤に隠れないようにする。

曲・音色・素材・保存形式・キー・戦闘計算・報酬・移動の仕様は変更しない。

## 検証

- 音声時刻停止、途中再生、終了、ジングルの置換、消音後の古いコールバックを検査する。
- 実AudioContextを停止してから勝利曲を予約し、曲全体より長い5.5秒間の実時間経過でも音声時刻・予約音・音符数を保持すること、再開後に次のBGMへ戻ること、消音で音源を解放することを確認する。
- 標準・小画面・横持ち・低い画面・320px幅・キーボード相当の高さで、タイトル音楽・設定ボタンの選択スクロール、操作盤より上に表示されること、48px以上の操作面積、ページエラーを確認する。
- 全体回帰、生成物照合、既存の実音声・波形・音楽操作の検査、必須CI、公開版のハッシュと関連操作を確認する。

ブラウザーによる模擬と自動波形検査であり、実機着信やイヤホン等での試聴ではない。利用者の既存セーブは検証に使用しない。
