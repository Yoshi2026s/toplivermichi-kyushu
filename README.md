**全国編：v5.34（2026年10月30日）**

男女混合アイドルグループを脱退したヒロインと旅立ち、トップライバーを目指す、スマートフォン向けの創作RPGです。街で依頼を受け、街の出口から街外MAPへ進みます。街と室内では敵に遭遇せず、通常戦闘とボス戦は街外のみで発生します。

ペット22種・10段階育成、65海域と3,250海洋敵、全100バッジ、5能力・22職業特性、33職歴・66記念装備、追加技・継承技・必殺技、状況別リスナーコメント、全47地域支援を収録しています。

MAPのパーティーキャラは、移動距離に合わせて足・腕・重心を動かす8段階の歩行表示になりました。停止中や動きを抑える設定では静止します。

MAP右上の「街外へ」で街の出口まで歩けます。街間は街外MAPの道を通り、隣の街外から街へ入ります。訪問済みの街への直行には、各街の新幹線駅を利用します。地図からの直接移動はできません。

MAP下には「やること」「オート移動」「メニュー」「設定・保存」を配置。左が「戻る」、右がスティックで、中央が決定です。地図・道具・ステータスなどはメニューから開けます。各画面の「MAPへ」でMAPへ直接戻れます。

編集元は `src/`、公開用はルートの `index.html` です。公開用HTMLは `node scripts/build.mjs` で再生成します。

スマホ向けの画面・タッチ操作は `npm run mobile`（または `node scripts/mobile-preview.mjs`）で専用のChromeを開いて確認できます。`npm run test:mobile` は4画面サイズでタップ操作・保存・ブラウザー再起動後の続行を検査します。[起動手順と検証範囲](docs/MOBILE_TESTING.md)を参照してください。物理端末やAndroid OSの実行とは区別します。

公開前は `node scripts/prepare-release.mjs` を実行します。ビルド、全回帰検査、生成物の一致確認、検証記録の更新を順に行い、成功時だけ `.task/release-v5.34-*/` に公開候補一式を作ります。画像10点（地形背景4点・キャラクターアトラス6点）、日本語フォント2点、フォントライセンスをHTMLへ埋め込みます。`node scripts/build.mjs --check` はファイルを変更せず、未ビルドの変更・素材欠落・古いマニフェストを検出します。この処理で公開サイトは更新されません。
