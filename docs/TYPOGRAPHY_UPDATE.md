# 文字デザイン更新（2026-10-30）

- タイトルを金色の二段組み明朝ロゴへ変更。見出し・地名・話者・戦闘結果にも明朝体を使用。
- 本文・メニュー・入力・操作・数値は日本語可変ゴシックで統一。太さ450／650／750等、字間、行間、見出しとの大きさを用途ごとに調整。
- 数値は等幅数字を指定。本文・操作説明は12px以上を維持。
- Shippori Mincho ExtraBold と Noto Sans JP から本作用のWOFF2サブセット（Quest Mincho／Quest Gothic）を生成。合計721,972バイト。
- フォント2点とライセンス全文をHTMLへ埋め込む。外部フォントサービスへの依存を解消。元のOFL全文と取得元は `assets/fonts/` に同梱。
- 通常のビルドと公開にはPython不要。フォント再生成だけ `scripts/subset-fonts.py` と fontTools を使用。
- 収録外の入力文字・絵文字は端末フォントにフォールバックする。

ローカルブラウザーでタイトル・MAP・メニュー・ステータスを240／280／320／375／390／430pxの24例で確認し、横方向のはみ出しなし。埋め込みフォントを使用した表示とコンソールエラーなしを確認。

機械検証は `node scripts/prepare-release.mjs` と `docs/validation-5.34.json` を参照。保存識別子、ゲーム内の操作、公開URLは従来どおり。
