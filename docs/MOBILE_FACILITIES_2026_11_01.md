# スマホ操作・ペット施設・MAP表示の更新

- メニュー文字を中央揃えにし、ボタンと欄に金の縁と奥行きを追加。中央は常に「決定」。戻るとジョイスティックは指の揺れを許容し、キャンセル・再描画・アプリ切替による誤実行を防止する。
- やることの受注中目標を上部に集約。オート移動に主要施設の絞り込みと最近の行先を追加し、到着と実際の操作可能距離を一致させる。
- 全52街でショップを商店街の空き建物、控え所を住宅区の空き建物に配置。購入はショップ、お世話・同行選択は控え所の近くでのみ許可し、ボタン表示と処理の双方で制限する。
- ペットメニューからは状態・習得技・将来の技と効果を確認。探索と戦闘には同行ペットを表示する。
- 水面・草・NPCの小さな動きを追加。演出抑制時は停止し、衝突位置・乱数・ゲーム状態に影響しない。ミニマップに施設略字を表示。
- 名前の英数字を半角化し、既存保存にも適用。パーティーMPは現在/最大で表示する。保存識別子・施設の既存控え所IDは維持する。

## 検査方法

`node scripts/check-mobile-facilities.mjs` は52街の施設配置・経路、場所制限、名前移行、MP、案内、演出停止を検査。`node scripts/test-mobile-facilities-ui.mjs` は6画面サイズでタッチ中断・実際の施設への歩行・購入とお世話の分離・再読込・戦闘・MAP演出を検査する。既存の全回帰・ペット・操作案内・戦闘結果検査も実施する。ブラウザーのスマホ模擬であり、物理スマホやOSキーボードの実機検証とは区別する。

## ローカル確認結果

全59回帰、生成物一致、追加スマホ6サイズ、既存ペット6サイズ、操作案内4サイズ、戦闘結果40ケースが成功。通常のMAP移動、街外の自然遭遇、戦闘と勝利報酬、MAP復帰も成功。CI・公開先での確認結果は公開記録に分けて記載する。

CIで見つかった小型画面のボス戦コマンドの重なりは、下部操作欄の余白を調整して解消した。主要タッチ領域は維持し、戦闘可読性検査4サイズで再確認した。CIの画面画像を残すため、指定した検査成果物の隠しディレクトリもアップロード対象にする。
