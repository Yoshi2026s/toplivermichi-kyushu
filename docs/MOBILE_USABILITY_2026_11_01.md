# スマホの表示・操作・可読性改善（2026-11-01）

## 修正した問題

- 長い戦闘進行文が味方やコマンドを大きく押し下げるため、プレビューを4行に制限。全文を読む操作で元の文章全体へアクセスでき、ログ・セーブは変更しない。
- 戦闘のHPとMPを14pxへ。状態表示を名前と並べ、同行ペットは名前と成長情報を分離。狭い横画面のMAPパーティーではペットを1列へ切り替え、横方向のはみ出しを防ぐ。
- AUTOの文字を意図した2行にして、狭い画面で末尾だけが折り返される状態を改善。
- 結果画面の体力・MP・要回復・報酬概要は14pxを確保。低い画面は主要な報酬・注意・MAP復帰を先に置き、状態と詳細はスクロールで読む。通常配置の復帰ボタンは本文を覆わない。
- 宿屋・休息の施設外メニューで、注意文を最初の閉じdivへ誤挿入し、見出しと戻る/MAPへ操作を押しつぶしていた。注意文を見出しの外の本文へ配置し、施設条件・費用・保存処理は維持。
- 金庫を含む入力欄を16px・48px以上へ。装備の数値は桁の途中で折り返さない。通知は画面幅に収め、下の操作へのタッチを遮らない。

## 検証

- 新規UI検査は6サイズで、通常メニュー31種類と戦闘メニュー5種類を確認。詳細を開き、画面下の操作までスクロールして実際にヒットできるかを検査する。
- 文字・数値の横見切れ、見出し幅、主要操作48px、入力16px、通知中の金庫入力保持、長い進行文の全文、AUTOのラベル、確定操作の位置を確認。
- 結果検査を6サイズ・66シナリオへ拡充。大きい報酬と5桁の報酬、長い名前、4人、戦闘不能、レベルアップ、旧記録、預かり/受取不可などを確認。文字を小さくして1画面へ押し込む検査を、文字14px・金額の見切れなし・重要概要がMAP復帰より上・詳細への到達性の検査へ置き換えた。
- ブラウザーのタッチ模擬。物理スマホ・OSキーボードは未確認。戦闘計算、報酬、保存キー、保存形式、用品や所持金の条件は維持する。

## 確認結果

- 全回帰60/60、構文検査・生成物照合・配布候補生成成功。最終ソースと検査記録のハッシュも一致。
- 6サイズ×36画面=216構成の表示・入力・下端操作が成功。結果66シナリオ、既存の戦闘可読性4サイズ、ペット育成と保存復元の小画面検査も成功。
- 5秒で消える応援字幕は、表示を待った直後に同じ件数・配置を検査するよう順序を調整。画像保存の待機時間で字幕が消えた後を検査しない。字幕の寿命・ゲームの時間・検査条件は変更しない。

### CIで検出した追加修正

CIの320px幅で、記録メニューの経験値欄に7pxのはみ出しを検出。共通レベルと経験値の説明を別行へ分け、項目名・値の折返しを明示した。値の省略やフォント縮小、検査許容幅の緩和はせず、項目名も追加検査対象にした。修正後のローカル216画面・全回帰60/60・生成物照合が成功。
