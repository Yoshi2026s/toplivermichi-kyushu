# 全国MAPの港画面・乗船音・操作制限

出発港の名称と船の図、行先・無料／未解放の状態を整理。乗船ボタンは実際の表示で64px以上の高さを確保する。港への操作は探索中で会話・別画面・操作ロックがなく、実際の港に近い場合のみ受け付ける。乗船も現在の画面・港・距離・解放状態を再確認する。

波音は専用の控えめな音量へ調整し、900Hzの帯域と25msの立ち上がりで鋭い高音のアクセントを除く。短時間の重なりを抑え、BGM音量は揺らさない。通常の効果音・BGM、歩行速度、保存形式、船の到着先・運賃は維持。

## 検証

- check-travel-modes.mjs：全国の港で戦闘・結果・タイトル・会話・設定・操作ロック中の操作を拒否し、既存の全陸路／船路・通行制限・旧保存互換を確認。
- test-world-ui.mjs：4サイズで港画面・64px操作・表示崩れ・不正な文脈から港を開かないこと・実際の乗船先を確認。
- check-sound-comfort.mjs：波音の音量・帯域・立ち上がり・鋭いアクセントなし・連打抑制・BGM非減衰を確認。
- test-audio-render.mjs：実音声処理のPCMで穏やかな立ち上がり、音割れなし、発音、完全な停止を確認。
- 72件の全体回帰検査・生成物照合、統合後は公開21ファイル一致・公開版のMAP操作／徒歩・船・保存復元を確認する。

実機スマートフォン・イヤホンの聴感確認は未実施。スマホ表示と操作はブラウザー模擬検証。
