# グラフィック更新（2026-10-30）

専用キービジュアル、海辺と森林の戦闘背景、地形素材と敵の描画を更新。

- `assets/title-journey.webp`: タイトル用の旅のイラスト（960×640）。
- `assets/battle-coast.webp`: 海岸・河川・湖畔の戦闘背景（960×540）。
- `assets/battle-forest.webp`: 森林・山・平野の戦闘背景（960×540）。
- 画像は imagegen で新規制作した創作風景で、実在の各都市を再現するものではない。
- `scripts/build.mjs` が画像を data URI として生成HTMLへ埋め込む。画像を差し替えた後は再ビルドする。
- 草・水の配色はマップの6種の地形に対応。石畳、瓦屋根、壁と窓、樹冠を再描画。
- 通常敵は64×64、ボスは128×128で描画。既存の表示寸法を保ち、光沢・目・輪郭を細かく表現。
- マップのタイル座標・移動・当たり判定・既存の保存データは従来どおり。
- メニューにはSVGアイコンを付加し、日本語ラベルも表示する。文字サイズは12px以上。

確認: `node scripts/build.mjs`、`node scripts/check-all.mjs`。ローカルのタイトル、街、街外をブラウザーで確認。公開反映と配信確認の手順は PUBLIC_RELEASE_CHECKLIST.md を参照。

戦闘画面は内容が多い場合に縦へスクロールでき、コマンドを圧縮しない。375px・240px幅で横方向のはみ出しがないこと、および実技戦闘の64px敵描画と海辺背景を実ブラウザーで確認した。
