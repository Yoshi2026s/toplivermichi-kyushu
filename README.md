# ポコチャクエスト｜トップライバーへの道 全国探索版

**公開版：v5.30（2026年10月29日）**

福岡編から阿蘇市編M08までの本編に加え、全国47都道府県・51拠点を訪問し、各地を探索できます。追加の43拠点は本版で新規制作した旅の土台です。固有の物語・本編依頼・地域ボス・配信は今後の制作対象で、参照版との一致も未確認です。

男女混合アイドルグループを脱退したヒロインと旅立ち、トップライバーを目指す、スマートフォン向けの創作RPGです。本編は**阿蘇市編M08まで**、その後は全国を巡る訪問・探索を収録しています。
