# 全国編 v5.33

2026年10月30日の依頼に基づき、全国の固有ストーリー・地域ボスと街／街外MAPを実装。

- 47都道府県・51拠点。既存M01～M08に43本の本編依頼、43名の案内人、86件の導入／完了会話を追加。
- 全51拠点の街MAPを新設計し、51枚の街外MAPを追加。地形は海岸・川・湖・山・森・平原。各街・街外のタイル配置はすべて異なる。
- 街と室内には遭遇区域もボスも置かない。街の出口を踏んで街外へ移動し、帰還口から街へ戻る。戦闘開始処理も街外限定。
- 街外ごとに3探索区域と地域ボス。追加ボスは6種類の行動周期、ガード／ダメージ／応援コメントによる対処を使用。
- 配信の準備・得点・4手番・再挑戦・配信待ちを廃止。ボス討伐で依頼完了・報酬・次の依頼と往路解放が確定する。
- 全国51依頼完了でS6とエンディング。旅の記録で完了した物語とエンディングを再読できる。
- 旧セーブの配信待ちは依頼完了へ移行し、未取得の達成報酬を1回だけ付与。既存完了依頼への再付与を防ぐ。所持品・金庫・育成・仲間を引き継ぐ。
- 地形更新前の保存位置は現在MAPの安全な到着位置へ補正。旧戦闘中セーブは戦闘と所持道具を維持して街外へ移す。敗北時は所属する安全な街へ戻る。
- 旅程枠廃止、MP、共有、育成上限、装備上限などv5.32までの仕様は維持する。

地理・物語・ボス・交通路の全件表は [NATIONAL_PREFECTURES.md](NATIONAL_PREFECTURES.md)。既存の実装計画は履歴資料であり、配信待ち・旅程枠に関する記述はこの版では適用しない。
