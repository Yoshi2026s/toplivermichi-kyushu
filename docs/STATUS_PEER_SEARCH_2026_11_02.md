# ステータスの2人比較・検索・回復導線

## 変更

仲間2人の12能力を横に並べ、装備・職業熟練度を含む現在値と「右－左」を表示する。左右の入れ替え、表示精度で差がある能力だけの表示に対応する。同じ仲間を選んだ場合は別の仲間を選ぶ案内を出す。比較相手の変更操作は折りたたみ、小画面で表を先に読めるようにする。

名前・職業を複数語で検索でき、全角／半角・英字大小・ひらがな／カタカナを区別しない。入力中には描画や検索を実行せず、検索ボタン・Enterで確定する。変換中のEnterは検索せず、未確定の入力も表示切替や装備との往復で保持する。HP不足・MP不足・戦闘不能の絞り込み、表示人数、条件解除を追加する。検索・絞り込みは比較相手の選択を変更しない。

比較一覧のHP・MP欄から回復道具の確認へ進める。戻ると検索・表示・比較条件を保持し、回復した結果は現在の絞り込みへ即座に反映する。比較一覧から「仲間へ移動」を選んだときに移動しない既存問題は、カード表示へ切り替えて対象へ移動するよう修正する。

保存形式・能力計算・価格・道具効果は変更しない。比較・検索は閲覧専用でも利用でき、道具使用は既存の保存・二重使用・古い確認の防止処理を利用する。

## 検証

全職業22×22×3レベルと9人の組合せ、計1,524モデルで能力値・左右入替・率の表示丸め・非破壊性を照合する。名前／職業の表記揺れと回復状態の検索も検査する。6画面サイズで検索・変換中Enter・入力保持・2人比較・差分・同一人物・閲覧専用・古い操作・戻り・直接回復・回復後の絞り込み・再読込を検査する。既存ステータス2系列と共通画面操作、全回帰・ビルド・生成物一致・CI・配信後の一致と操作を確認する。実機スマートフォンとOSキーボードは未確認。
