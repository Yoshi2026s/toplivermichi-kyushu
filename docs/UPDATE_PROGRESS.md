# Yoshi2026s 公開版の更新状況

2026-10-29。基点は公開中の v5.29。統合更新指示書の v10.108 相当は、参照元の後続ソースが未入手のため完成扱いにしない。

## 今回の実装

- `src/ui.js`: 預かり品の自動受取を、操作可能な安全地帯の探索画面に限定。実際に受け取った場合は保存する。
- `src/ui.js`: 宿泊・無料休息・新規開始・復元の入口と画面状態を確定時に再確認。古いボタンや直接呼出しを拒否する。
- `src/ui.js`: 復元入力欄の欠落を安全に扱い、復元時のオート戦闘・移動経路・会話・選択を解除する。
- `src/ui.js`: 編成を1～4人で追加・離脱・順番変更・指定枠との直接入替に対応。古いボタンと禁止状態からの変更を拒否する。
- `src/ui.js`: 職業・装備・地域支援の確定処理に画面・解放条件・対象IDの再確認を追加。
- `src/core.js`: 敵の単体攻撃の対象を前衛ほど多く選ぶ巡回重み（4人なら4:3:2:1）へ変更。戦闘不能者は除外する。
- `src/ui.js`: 敵カードから次行動・対象・予測ダメージの表示を除き、撃破後の状態表示を残す。
- `src/ui.js`: ショップの購入・売却で施設、商品、売買区分、数量、単価、所持数、上限、所持金を確定時に再照合。不正数量、古いボタン、施設外からの確定を拒否する。数量上限に「個」を表示。
- `src/ui.js`: 道具の使用・廃棄を探索中の道具画面に限定。廃棄確定時に品目と所持数を再照合し、古い確認ボタンや連打で二重に減らさない。
- `src/ui.js`: 依頼の受注・放棄と地域ボス挑戦で、画面、依頼状態、現在地、近くのボスを確定時に再確認。古い操作による旅程枠の二重消費や依頼進行の変更を防ぐ。
- `src/ui.js`: 地図と門からの拠点移動で現在画面、安全地帯、行先、門との隣接を確定時に再確認。古い移動ボタンや未収録の行先による旅程枠消費を拒否する。
- `scripts/check-shop.mjs`: 数量の境界、装備中の売却除外、状態変化による確認トークンの失効を検証。
- `src/data_national.js`: 全国8地方・47都道府県の永続ID台帳を追加。ドラフトPRでは福岡県の `KY01`・`KY02` と佐賀県唐津市の `KY03` を紐付ける。
- `src/ui.js`: 地図画面に全国編の準備状況と現在遊べる範囲を表示。
- `scripts/check-national.mjs`: 47都道府県の正式名・順序、8地方の内訳、現行拠点との対応を検査。
- `src/data_national.js`: 福岡市↔北九州市と北九州市↔唐津市をID・進行条件付きの移動可能な経路として登録。唐津への入口は福岡編完了で解放する。
- `src/ui.js`: 地図と門の移動確定時に、実装済み経路と解放条件を再検査。唐津の初回到達は北九州の東門からに限定する。
- `scripts/check-national.mjs`: 経路IDの重複、接続先、実装状態、現在遊べる拠点間の到達性を検査。
- `scripts/build.mjs`: `src` の10本の JavaScript と `shell.html` から `index.html` を再生成できるようにした。
- `src/data.js`: 佐賀県唐津市の安全な探索拠点を追加。案内人、海辺の案内板、宿泊、休息、編成、記録と北九州への帰還に対応。初回到達時は既存の加入予定どおり航平が仲間に加わる。
- `src/ui.js`: 訪問した拠点と唐津の会話を記録に表示し、地図に唐津編M03までの実装範囲を明示。
- `scripts/check-national.mjs`: 唐津の門の往復先、安全地帯からの徒歩経路、必要な施設と会話の配置を検査。
- `src/data.js` と `src/data_saga_enemies.js`: 唐津の3探索区域、地域ボス、主編依頼M03、佐賀の配信手順を追加。各区域の敵は既存の敵プロフィール50種を再利用する。
- `src/core.js` と `src/ui.js`: 福岡編M02完了でM03を解放し、戦闘・ボス・配信を完了できるようにした。旧セーブにM03の初期状態を補い、所持品と進行を保持する。
- `scripts/check-saga.mjs`: M03解放、旧セーブ移行、区域とボスの戦闘生成、配信達成、報酬の二重受取防止と佐賀の地域支援効果を検査。
- `src/data.js` と `src/ui.js`: 佐賀の地域支援「佐賀の声」を追加。唐津の案内人との会話とM03完了で選択でき、戦闘開始時のエールを12増やす。選択確定時も解放条件を再確認。
- `src/data.js` と `src/data_national.js`: 唐津編M03完了で佐賀市の安全な探索拠点を解放。唐津の東門から初回到達し、案内人、宿泊、休息、編成、記録と唐津への帰還に対応。佐賀市の依頼・戦闘は未収録。
- `scripts/check-national.mjs`: 佐賀市の門の往復、徒歩経路、施設と会話、M03解放条件を検査。
- `src/data.js` と `src/data_saga_enemies.js`: 佐賀市の探索3区域と案内板を追加。敵プロフィールは既存50種を区域ごとに再利用し、地域ボスと主編依頼は未収録。
