# 全画面の表記・説明の整理

## 整理した内容

- 街・街外：所持金の単位を他の画面と同じGへ。移動の解説は、街外を歩く・海は港から船・未解放地域には入れない現在の仕様に合わせる。
- 戦闘：自動戦闘で繰り返す一般説明を除き、現在の行動と手動へ戻る操作を残す。見出しを「敵」「仲間」へ整理し、仲間の操作案内を実際の選択操作に合わせる。空の履歴は「行動の記録はありません」と表示する。
- 結果：使用道具の見出しを短くし、履歴がない場合と道具未使用を区別する。一部の履歴だけがある場合は「記録のある分」と明記する。
- 全メニュー：検索の「解除」を「クリア」へ統一。入力語だけを消す操作と、絞り込みも戻す操作の違いは読み上げ用の名前で示す。空の結果は品物・装備・職業・解説など対象を明確にする。
- 設定・共有：繰り返す操作説明を短縮し、難易度の適用時点・復元の上書き・バックアップ保管・共有ではセーブを送らないことを残す。
- 案内板・ボス・記録・作品情報：内部向けの「強度q」「schemaVersion」を利用画面から除き、ボス名・推奨レベル・現在レベル・ゲームのバージョンを残す。物語ランクの条件は依頼コードだけでなく依頼名で示す。非公式の創作であること、実在のサービスとは連携しない説明は残す。
- ペット・施設・閲覧専用：日次回数・日付変更では戻らない条件を残して短縮。施設の利用場所と閲覧専用の説明を短くする。

オート戦闘へ切り替えた時は、操作欄を下部パッドの上へ表示する。開始時だけ調整し、その後の再描画で選んだ読書位置を動かさない。

料金・受取先・廃棄や復元の確認、敗北時の減額、道具の使用記録の不明／未使用、回数制限、遭遇と未解放地域の制限は削除しない。操作の識別子・API・保存キー・形式・進行・戦闘計算は変更しない。
