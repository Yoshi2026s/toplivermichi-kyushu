# 音声停止中の効果音と設定の状態案内（2026-11-02）

公開main 1169ce5を基点に、音声が停止している間に古い効果音が予約される経路と、音声状態が分かりにくい設定表示を修正。

- 停止・割り込み・終了状態では新しい効果音を予約しない。状態変更時には予約済み効果音と連打抑制の履歴を解除し、復帰後の新しい操作音を受け付ける。BGM・ジングルの音楽時計は維持。
- 試聴は音声の復帰完了を待ち、復帰に失敗・消音・画面切替・閲覧専用化した場合は鳴らさない。通常の効果音は停止中に後回しにしない。
- 設定に音声の一時停止・開始操作・全体OFF・個別消音を示す案内を追加。状態変更時はライブ領域の文章だけを更新し、入力欄・フォーカス・選択範囲を再生成しない。
- 音声の初期化に失敗した後に届く状態通知も無視し、例外を出さない。失敗を起こす装置モデルと遅延通知で回帰検査する。
- 曲・音源・音量値と保存キー/形式、音楽時計と進行ルールは変更しない。

## 検証

- 修正前に、停止中の効果音で音符・ノイズ・BGM減衰が追加される検査の失敗を確認。修正後は停止/割り込み/終了を含むガードと、復帰中の消音を検査。
- 実ブラウザーのAudioContextを一時停止し、古い効果音の予約抑制、予約済み効果音の解除、新しい音の復帰、試聴の復帰待ち、状態表示、同じ入力DOM・内容・選択・フォーカスの維持を検査。単体モデルでは割り込み時のBGMの保持と効果音解除も確認。
- 64条件の波形試験では、停止中からレンダリング用の予約を行うOfflineAudioContextに対し、稼働中の装置を表すファサードを使用。有限波形・ピーク・最大RMS・解放後の無音等の判定は維持し、停止制御そのものは実ブラウザーのAudioContextと単体の状態モデルで別途検証する。
- 設定6サイズ、音量5サイズ、保存音量6サイズ、タイトル/探索/戦闘の左右波形、全体回帰・生成物照合・必須CI・公開版の結果は公開確認記録へ記載。
- 案内に使う全字が両同梱フォントに収録されていることを確認。

画面はブラウザー模擬。音声一時停止もブラウザーAPIによる検査であり、実際の通話・Bluetooth・イヤホン・物理スマホの確認ではない。利用者の既存データを使わず、復元送信も行わない。
