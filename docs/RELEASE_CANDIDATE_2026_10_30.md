# グラフィック・MAP操作の公開候補

2026-10-30。アプリ版5.34、保存形式5。

## 含む変更

- 専用のタイトル画像と海辺・森林の戦闘背景。画像3点は約657KBのWebPで、生成HTMLへ埋め込む。
- 石畳・屋根・窓・樹木、6種の地形配色、敵64px／ボス128pxの描画。
- MAP下は「やる事」「オート移動」「メニュー」。その他の11項目はメニュー内。
- 現在地・安全区分・近くの対象は上部、街外／街へ戻るボタンはMAP右上。
- 左に戻る、右にスティック。中央タップで決定し、ドラッグ・キャンセル・非表示復帰時の誤発火を防ぐ。
- 各メニューにMAPへ直接戻る操作。通常の戻るは前のメニューへ戻り、航海も実際の呼出元へ戻る。
- 地図切替時の描画ループの重複防止。

## 公開前の確認

`node scripts/prepare-release.mjs` がビルド、回帰検査、生成物の再現性検査、検証記録の更新、公開候補フォルダー作成を行う。途中で失敗すると成功した公開候補として出力しない。

`node scripts/build.mjs --check` は読取専用。生成HTML、仕様TXT、マニフェストがソース・文書・画像と一致することを確認する。回帰検査では隔離したコピーで古いHTML、変更／欠落した画像、古いマニフェストが拒否されることも確認する。GitHub Actionsも再ビルド前にこの照合を行う。

最新の機械検証は [validation-5.34.json](validation-5.34.json)。ソースはUTF-8/LF、画像と公開ファイルは実バイト列でSHA-256を記録する。

ブラウザーでは前工程でMAP・全11メニュー・戻る履歴・MAP直接復帰・中央決定を確認し、375px／240pxで横方向のはみ出しがないことを確認した。これはデスクトップブラウザーでの画面幅検証であり、スマートフォンやBluetoothコントローラーの実機検証ではない。
