# 街中・街外・戦闘・結果・全メニューの表示改善

街中の安全表示と、街外の現在地点の遭遇あり／なしを区別する。エリア全体が安全とは表示せず、遭遇区域の警告を維持する。出入口の読み上げには行先と徒歩操作を含め、地域をまたいだ際も更新する。目標欄には軽い輪郭を付け、表示位置・歩行ルールは維持する。

全画面のキーボード選択枠を内側に描き、スクロール枠で切れにくくする。スティック選択とメニューの選択済み表示も揃える。戦闘記録・結果詳細は48px以上の開閉と、開いた状態の見分けを改善する。

戦闘の味方対象はHPとMP上限を示し、蘇生対象は戦闘不能・HP0を明示。結果の経験値・ゴールド・チケット・所持金は省略表示を保ちつつ、全桁をツールチップと読み上げに含め、タッチでは従来の詳細欄から確認できる。戦闘計算・報酬・保存形式は変更しない。

## 検証

- test-screen-clarity.mjs：6条件で街内の安全／街外の遭遇なしと実際の遭遇区域を区別し、出入口の行先、全画面のキーボード選択枠、蘇生対象、結果の全桁、詳細の48px操作・横はみ出しを確認。
- test-result-overview.mjs：6条件・66ケースで結果の概要、低HP／戦闘不能、報酬とMAPへの戻り操作を確認。
- test-mobile-usability.mjs：36メニュー×6条件で入力・48px操作・最後の操作への到達性を確認。
- 既存の戦闘4サイズ、表記・検索入力保持・戻る操作、結果の読書位置保持、全体72検査と生成物を照合する。
- 統合後は公開21ファイル一致と公開URLの街・街外移動・船・戦闘・結果・メニューを検証する。

実機スマートフォン・OSキーボード・読み上げ機器の実操作は未検証。6条件はブラウザー模擬検証。
