# お知らせとコピー・復元欄の読みやすさ

街・街外・戦闘・結果とメニューのお知らせは、短い文は従来どおり最低2.6秒、長い文は文字数に応じて最大12秒表示する。行間を1.5にし、読み取りやすくする。次の主ボタンのタッチまたは通常のキー操作で前のお知らせを退け、確認したい操作を隠し続けない。通知は入力を横取りせず、退けるためだけの操作も要求しない。修飾キーだけの操作やIME変換中のキーでは消さず、再描画では通知を維持する。置き換え時は古いタイマーを解除する。

設定のバックアップ出力欄に見える名前とコピー方法を付ける。復元欄にも見える名前を付け、現在の記録を置き換える説明を関連付ける。貼り付ける文字列の大文字化・自動補正・スペルチェックを抑制し、再描画時の入力・選択位置保持を保つ。共有URLの既存ラベルは維持し、セーブは送られない注意書きと関連付ける。

保存キー・形式・復元処理、移動経路・戦闘計算は変更しない。

## 検証

- `check-notice-readability.mjs`：通知の長さと期限の上下限、旧タイマーの取消、置き換えた通知の保持、退けた通知の再表示防止を模擬時計で検証する。
- `test-notice-input.mjs`：街・街外・戦闘・結果・メニューの5場面を6画面条件で確認。通知のプレーンテキスト表示・可視範囲・タッチとキーによる退去・修飾キーと変換中の保持・記録非変更を検証する。出力欄の名前と読み取り専用、復元欄の説明・補正抑制・入力と選択位置の保持、共有欄の説明も確認する。
- 既存の通知表示、設定の入力保持、全36メニュー、移動・戦闘・結果・メニュー往復と73項目の回帰検査、生成物の照合を実施する。
- 統合後、公開21ファイルの一致と公開URLの主要操作を再確認する。

標準・小画面・横向き・低い高さ・幅320px・入力時相当の高さをブラウザーで模擬する。IME中のイベントは合成であり、実際のOSキーボード、実機スマートフォン、読み上げ機器は未検証。
