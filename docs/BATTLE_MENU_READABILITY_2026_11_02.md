# 戦闘画面・共通メニューの読みやすさ改善

冒険メニューを3つの用途に分け、11項目に短い説明を追加。既存の名称・移動先を保ち、説明文をaria-describedbyで関連付ける。

全ての共通メニュー枠に対し、説明文の文字・行間、数値の桁の揃い、選択肢と詳細開閉の48px以上の操作面積を整える。実際の見出しの高さからスクロール余白を設定し、入力や操作が固定見出しに隠れにくくする。画面サイズ変更時も更新する。入力やスクロールを別ノードへ置き換える追加処理は行わない。

戦闘コマンドに選択中の仲間・現在MP／上限・操作段階を表示。敵・味方の対象にHPなどの状態を添え、確定前の効果予測に仲間名と行動名を表示する。選択状態の輪郭と行間を整え、戦闘計算・行動条件・オート戦闘・保存形式は変更しない。

## 検証

- test-mobile-usability.mjs：36メニューを6条件（通常・小画面・横向き・低い高さ・幅320px・キーボード表示を想定した高さ）で検査。共通見出し余白、分類と説明の関連付け、文字欠け・入力文字・48px操作・最後の操作への到達性、長い名前や戦闘ログ、対象HP・仲間／行動の確認表示を検証。
- test-battle-readability.mjs：4サイズで敵表示・主要操作・対象選択・確定・オートと手動・コントローラーとの重なりを確認。
- test-mobile-facilities-ui.mjs：分類後のメニュー、物理的な戻る操作、施設とペットの主要操作を確認。
- 検索・入力の保持、72件の回帰検査・生成物照合、最新PRのCIを確認する。統合後は公開21ファイル一致と公開URLの戦闘・メニュー操作を再検証する。

スマホ操作はブラウザー模擬。実機スマートフォン・OSキーボードでの実操作は未検証。

補足文の共通指定は画面固有の文字サイズを上書きしない低い優先度とし、従来14pxの依頼情報などを維持する。test-mobile-copy.mjsでも6条件の補足文字・見出し・主要操作を確認する。
