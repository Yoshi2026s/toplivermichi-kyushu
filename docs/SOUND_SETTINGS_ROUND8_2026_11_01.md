# 音量と設定表示の改善 第8回（2026-11-01）

PR #67の公開版を基点に、タイトルからの音量調整を改善する。

- 保存済みの冒険から音量を読み込んだ後、タイトルの設定表示と一時設定の初期値を、実際のBGM・効果音の音量へ合わせる。たとえばBGM25％・効果音50％で再生中に、設定表示が100％になる問題を修正する。
- 片方の音量だけを変更しても他方を100％へ戻さない。音量0や、すでに選択した一時設定も保持する。
- 音量ボタンで設定画面を再描画しても、スクロール位置と操作中のフォーカスを保持する。
- タイトルでの調整は従来どおり一時設定とし、既存の冒険の保存データを変更しない。再読込すればその冒険に保存された音量を読み込む。曲・音色・素材・保存形式・キー・ゲーム計算は変更しない。

## 検証

- 修正前に、保存音量25％・50％と設定の選択表示が一致しないことをブラウザー検査で再現する。
- 標準・小画面・横持ち・低い画面・320px幅・キーボード相当の高さの6サイズで、保存・再読込後の表示、独立した音量変更、スクロールとフォーカス、音量0からの設定再表示、既存保存データの不変、再読込後の音量を確認する。
- 既存の音量操作検査、全体回帰、生成物照合、必須CI、公開版のハッシュと関連操作を確認する。

ブラウザーでの端末模擬と自動検査であり、物理スマホ・イヤホン等での実際の試聴とは区別する。検証用の新しい保存データだけを使用する。
