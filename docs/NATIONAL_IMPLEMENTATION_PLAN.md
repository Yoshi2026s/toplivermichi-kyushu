# ポコチャクエスト Yoshi2026s全国編 実装計画

**v5.33で全国の固有物語・地域ボス・街／街外MAP分離を実装。現在の仕様は [NATIONWIDE_5_33.md](NATIONWIDE_5_33.md) と [全件台帳](NATIONAL_PREFECTURES.md) を参照。以下は過去の計画。配信待ちと旅程枠に関する項目は2026年10月30日の更新では適用しない。**

公開版v5.30は本編M08までと全国47都道府県の訪問・探索を収録。全国追加拠点の固有本編は追加開発要件。現在の実装状況は[UPDATE_PROGRESS.md](UPDATE_PROGRESS.md)を参照。

## 実装範囲

この計画はユーザーが新たに指定した**全国編の実装範囲**。旧版更新履歴や参照数値を、全国47都道府県の完成を示す証拠として扱わない。現在のコードは `src/data.js` の福岡市・北九州市と第1章が中心であり、全国の地名、人物、依頼、敵、報酬、配信シーンの正式な本文は未確定。旧ソースを回収できた場合は内容を照合し、回収できない部分は新規創作として記録する。

### 完成範囲と地理データ

- 北海道、東北、関東、中部、近畿、中国、四国、九州・沖縄の**8地方・47都道府県**を旅行・物語進行の対象にする。各都道府県に少なくとも1つの到達可能な拠点、入退出できる安全地帯、地域に対応する探索区域、遭遇または明示された非戦闘イベント、図鑑・記録への導線を設ける。既存の福岡市・北九州市は再実装せず、互換性を保って全国データに組み込む。
- `prefId`、`hubId`、`mapId`、`areaId`、`routeId`、`questId`、`enemyId`を重複しない永続IDで管理する。名称や表示順を保存IDの代用にしない。47都道府県の正式名・地方・拠点・接続先・解放条件・推奨レベル・主な登場人物を一覧表にし、実装前に未決定欄を明示する。県数や地方別内訳はデータから自動検査する。
- 陸路・駅・港・航路は到達可能な経路グラフとして定義する。解放条件と旅程枠を通過・確定時に検査し、未解放先への直行、行き止まり、戻れない移動、別セーブの解放状態混入を防ぐ。47都道府県の拠点が開始地点から条件達成後に到達でき、帰還できることを自動検査する。旧版資料の海域65等は参照規模であり、全国編の県数から機械的に生成しない。

### 物語・地域コンテンツ

- 現行の第1章福岡と既存セーブの進行を保持し、全国編の章・地方別の依頼、加入人物、配信、地域ボス、エンディングを段階的に追加する。各地方には開始条件、目標、道中の変化、地方の到達点を設定し、主編の進行順と自由移動でできる範囲を区別する。都道府県固有の会話・場所・敵・報酬は創作内容として資料化し、未確定のものを完成扱いにしない。
- 依頼は「未解放／受注可能／進行中／ボス待ち／配信待ち／完了」を保存し、条件を満たしたときだけ遷移する。放棄、敗北、撤退、再読込、連打で進行や報酬が重複しない。地方をまたぐ依頼や仲間の加入も対象セーブの状態だけを参照する。
- 地域支援は旧版資料にある九州・沖縄の参照条件を維持しつつ、全国の追加分を別表で設計する。支援ID、解放条件、効果、エール上限、戦闘開始時の固定値を共通データから表示・計算する。数値は現行バランスを確認して確定する。

### 実装順と成果物

1. **基盤を固定**：`src/` と `scripts/build.mjs` を正規編集元とし、生成した `index.html`、版情報、進捗表を一致させる。現在のドラフトPRで行った保存・編成・ショップ・依頼・移動の安全対策を保持する。旧版後続ソースと資料が見つかれば版・ハッシュ・権利・差分を記録して取り込む。
2. **全国データの骨格を作成**：47都道府県と8地方の一覧、永続ID、経路、解放条件をコード外でも確認できる仕様表にする。最初に福岡と隣接地域で縦断の遊べる区間を作り、同じデータ形式で地方を広げる。未収録の行先はゲーム内で選べないようにする。
3. **地方単位で完成**：各地方の地図、拠点、依頼、会話、敵、ボス、配信、地域支援、図鑑、音と画像を一まとまりで実装する。各地方の到達・帰還・保存再開・旧セーブからの移行を確認してから次の地方へ進む。地方別の完了表に実装コミットと検査結果を残す。
4. **横断システムを統合**：統合更新指示書にある戦闘チャレンジ100種、ペット、金庫、コメント、オート回復、海域・航路、音響を全国データと接続する。システムの完成と47都道府県の完成を別々に判定し、片方だけで全国編完成とは呼ばない。
5. **公開準備**：全地方と横断システムの受け入れ条件を満たし、旧セーブ・バックアップ・閲覧専用タブ・スマートフォン表示を確認する。PRの差分を確認し、mainへ反映後にPagesの公開URLと配布ファイル・版情報の一致を照合する。

### 全国編の受け入れ条件

- 自動検査で47都道府県の重複・欠落がなく、8地方の所属が一致し、全拠点と経路の参照先が存在する。開始地点からの到達と帰還、封鎖条件、旅程枠不足、徒歩・オート移動・船移動の中断を検査する。
- 各地方で少なくとも1本の主編進行を開始から地方の到達点まで遊べ、依頼・戦闘・配信・報酬・記録が保存再開後も整合する。全47都道府県の拠点を実ブラウザで到達確認し、未実施の県を一覧に残す。
- 旧v5.29のセーブとバックアップを読み込んでも、福岡編の進行、仲間、持ち物、装備、ゴールド、依頼、図鑑を失わない。既存の保存形式を無根拠に変更せず、必要な移行は明示したバージョン付き処理と検査を追加する。
- 全国編のタイトル・README・版情報に実際に遊べる範囲を表示する。47都道府県の実装、横断機能、公開URLの照合がすべて済むまで「全国編完成」「v10.108相当」と表示しない。部分公開する場合は対応済みの地方・県と未実装項目を明記する。
