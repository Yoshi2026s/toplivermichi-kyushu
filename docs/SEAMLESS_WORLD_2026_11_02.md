# 全国街外・同行・優先案内

2026-11-02。全国の街外はJP-WORLD上で連続歩行する。元の地域MAPは景観の編集元と旧保存データへの互換位置として保持する。街・室内と港の船移動では従来どおり移動先へ入る。

全国概略図・ミニMAPに全51拠点を表示し、未解放地域を紫色と通行制限で示す。解放は元のルート条件から導出し、新設の連絡道だけでは先の地域を開かない。海上区間は港付近からのみ出航し、目的港へ到着する。陸上の自動移動はA*、案内の距離は更新時に一度計算して再利用する。全世界サイズの画像は生成しない。

ペットの画像は既存の許諾済み素材を使う96×112pxの4方向・8歩行表現。仲間とペットは実際の歩行履歴を追い、ペットはパーティー後方に並ぶ。キャッシュは64枚まで。道順は実行時だけ保持する。

案内では体力・使える回復道具・宿代・到達距離・受注状況・解放済みの本編を評価する。古いボタンや閲覧専用状態からの移動変更を拒否する。レベルアップは8小節の楽曲を短い先読みで再生し、音量設定・消音・中断を尊重する。結果画面には次のレベルと必要経験値を表示する。

## 検証

- check-travel-modes: 全51街の往復、陸路と船路の双方向、未解放地域、旧セーブと全国位置の復元、新幹線の既訪問条件。
- check-integration: 全51本編を受注・雑魚戦・ボス・結果処理まで完走。
- check-levelup-score: 8小節の終端、音声時計停止時の保持、先読み範囲、中断。
- test-world-ui: 4画面サイズの全国図、48px操作、同一canvasでの連続歩行、曲がり角の同行、描画サイズ上限。
- test-result-overview: 6画面サイズ×11条件でMAP帰還・経験値・仲間の状態の可読性。

これらは自動検査とブラウザー模擬検証であり、物理スマートフォン・イヤホンの聴感確認を意味しない。

## 保存の再起動・復元検査

全国の街道上の位置を、再読込・ブラウザーの完全終了と再起動・バックアップからの復元と再読込で照合する。戦闘中の全国位置と戦闘後の戻り先も再読込して確認する。旧地域MAPの正常な位置は座標だけ変換して引き継ぎ、実際に不正な位置を安全地点へ戻した場合だけ回復の案内を表示する。test-world-save.mjsで継続検査する。
