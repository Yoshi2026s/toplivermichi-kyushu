# ポコチャクエスト v5.31 整合性修正

更新日：2026年10月30日（日本時間）。対象は `Yoshi2026s/toplivermichi-kyushu` の既存公開版。新しい大型機能の追加は行わない。

## 今回の確定仕様

- 旅程枠は廃止。移動・依頼受注で枠を使わず、休息による枠回復もない。物語進行、安全地帯、初回の門、経路、操作中状態などの条件は維持する。旧セーブの `slots` は無視し、冒険のデータは削除しない。
- 主人公名は全角1～12文字。編成は1～4人で全員入替可能。名前・編成の計算方式は今回変更しない。
- 未装備品は最大300種類。同じ装備を複数持っても1種類。同一装備の8個上限は装備中・手元・金庫を合計する。アイテム金庫は全カテゴリ合計999個のまま。購入、金庫引出、熟練度の贈り物、装備解除・転職で種類数を確認する。旧在庫は消さず、上限超過の旧記録は超過を増やさず整理できる。
- 総合経験値・レベルは共通。職業熟練度は戦闘参加者別。控えの総合レベルには共通経験値が反映されるが、控えに戦闘熟練度は加算しない。
- 利用者向けの「集中力」「CP」はMPへ統一。内部の `c`、`startC` 等の保存キー、MP計算、回復量は名称変更では変えない。
- セーブ全削除・全員再スタートは行わない。保存形式番号は5のまま。バックアップと既存記録を維持する。

## 本編進行による上限

| 関東編 | 600 | 本編未収録・未解放 |

章ごとの終了本編依頼を `STORY_CHAPTERS[].completionQuest` に登録し、その実在する本編依頼が完了した場合だけ次の章の上限を開ける。未収録の章終了依頼は `null` のままとし、県への訪問、M02、M08、保存内の自己申告の完了フラグでは解放しない。将来の追加章でも上限100ずつを基本に定義し、最終上限は999を超えない。今回、新しい本編章は制作しない。

通常は現在上限までの経験値・熟練度だけを加算する。旧版で上限を超えていたセーブは初回移行時に総合レベルとキャラ・職業別の到達熟練度を記録し、元の経験値・熟練度・既存の到達値を維持する。記録された到達値と章の上限の高い方を有効上限とし、章の進行が追い付くまでは超過育成を進めない。上限で報酬の経験値が0になってもゴールドと依頼報酬は独立して受け取れる。

## ボス固有報酬

通常敵1体の報酬は、強度qに対して経験値 `8 + 3q`、ゴールド `20 + 2q`。今回の設計では同じ強度の通常敵3体分をボス固有報酬とする。難易度や同行人数では増減させない。経験値は現在の有効上限まで。

| ボスID | 強度q | 固有経験値 | 固有ゴールド |
| --- | ---: | ---: | ---: |
| LB01 | 3 | 51 | 78 |
| B01 | 8 | 96 | 108 |
| B02 | 11 | 123 | 126 |
| B03 | 14 | 150 | 144 |
| B04 | 17 | 177 | 162 |
| B05 | 20 | 204 | 180 |
| B06 | 23 | 231 | 198 |
| B07 | 26 | 258 | 216 |

本編依頼の達成報酬（経験値40・チケット200）、任意依頼の達成報酬（経験値10・チケット80）、既存の品物は別に維持する。M01はボス撃破で依頼が直接完了するため、初回は固有経験値51＋依頼40となる。配信を要する依頼では、ボス固有報酬と配信後の依頼達成報酬を別段階で受け取る。同じ戦闘の再表示・保存再開では `rewardsApplied` により二重支給しない。

## 検証と限界

既存12本と追加 `scripts/check-selected-fixes.mjs` を使用する。章終了条件、全国訪問による誤解放防止、旧上限超過記録の保持、300種類と同一装備8個、金庫移動、ボス報酬の二重支給防止、待機者の熟練度不変、12文字、MP表記を確認する。

これらはNode上の処理・模擬画面検査。今回のスマートフォン実機・実際の旧セーブ・音の聴感は未確認。公開配信の確認はコード保存と区別し、実際の配信結果を照合して報告する。
