# 音声復帰・タイトル表示の改善 第6回（2026-11-01）

PR #65の公開版を基点に、音声の割り込み復帰とタイトルの案内を改善する。

- 音声を有効にする操作と復帰操作で、`suspended`に加えて`interrupted`も`AudioContext.resume()`の対象にする。再生中の曲・ジングルを再スタートせず、消音中の復帰操作では音を有効にしない。再開が拒否されても未処理のPromise拒否を発生させない。
- タイトルの再生待ち表示を「BGMを再生・再開」に変更する。中断後にも「最初のタッチ」と案内していた表示を修正する。
- BGM音量0では「BGM音量0・設定」と表示し、読み上げ名も「BGM音量の設定を開く」にする。ボタンの実際の動作と案内を合わせる。音量0を勝手に変更しない。

曲・音色・素材・保存キーや形式、戦闘・報酬・移動の仕様は変更しない。

## 検証

- 音声の4状態と再生スケジューラの有無を組み合わせ、復帰対象、曲とジングルの維持、再開拒否、消音の保持を検査する。
- タイトル音楽のブラウザー検査を6サイズ（標準・小画面・横持ち・低い高さ・320px幅・キーボード相当の高さ）へ拡張する。実AudioContextを一時停止し、状態だけを割り込み中に模擬して、Enterキーによる復帰と再生表示を確認する。保存・再読込・音量0の設定案内、場面切替の既存検査も維持する。
- 既存の音声波形・音源数・25場面の検査、全体回帰、生成物照合、必須CIと公開版確認を行う。

割り込み状態の仕様は[WebKit自身の検査](https://github.com/WebKit/WebKit/blob/main/LayoutTests/webaudio/audiocontext-state-interrupted.html)を参照。ブラウザーの模擬検査であり、実際の着信・物理スマホ・イヤホンでの試聴を確認したものではない。OSが再開を許可しない間の強制再生は行わない。
