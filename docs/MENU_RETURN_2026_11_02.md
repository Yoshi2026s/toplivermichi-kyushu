# 全画面のメニュー往復・操作位置改善

前のメニューへ戻る際に、スクロールと実際に押したボタンを復元する。街・街外・戦闘・結果から開いたメニューを閉じる場合も元の操作へ戻す。画面本体と下部の同じ操作は区別し、元の操作が詳細内なら祖先の詳細を開いて戻る。結果の読書位置は保つ。街・街外では移動モードのまま、戦闘・結果の中央ボタン案内は選択された操作に合わせる。

戻り先には元の記録・画面・領域・識別情報だけを一時的に持ち、再描画後の有効な一意の操作だけを選ぶ。古いDOMを保持せず、無効・非表示・別の記録は無視する。保存形式・URL・移動と戦闘の計算は変更しない。入力欄を勝手にフォーカスせず、画面キーボードを不用意に開かない。

メニューアイコンと重なっていた旧カーソルの疑似要素を除き、選択は既存の強調枠で示す。選択してもアイコンと項目の高さが変わらず、スクロール位置がずれない。戻るボタンの説明も、前のメニュー／元の画面に応じて示す。

## 検証

- test-menu-return.mjs：6条件で街・街外・戦闘・結果からの実際のEnter／タッチ操作、親メニューの項目とスクロール、中央ボタンの再操作、アイコン配置、結果の読書位置、無効と別記録の拒否、閲覧専用時の記録非変更を確認。
- test-result-reading.mjs：4サイズの詳細の開閉と読書位置保持。
- 既存の36メニュー×6条件、操作・ナビゲーション、検索入力、72回帰検査と生成物の照合を確認する。
- 統合後、公開21ファイル一致と公開URLのメニュー往復・街／街外移動・戦闘・結果・全メニュー操作を再検証する。

実機スマートフォン・OSキーボード・読み上げ機器での操作は未検証。ブラウザー模擬検証を使用。
