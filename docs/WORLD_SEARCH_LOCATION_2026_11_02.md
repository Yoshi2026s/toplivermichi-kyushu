# 全国MAPの検索位置表示・BGM選曲改善

検索語や解放状況の絞り込みに一致する地域を水色の点線で強調し、「検索結果を見る」で全該当地域が収まる1・2・4倍の最大倍率と中心を選ぶ。地図へスクロールし、キーボードのフォーカスも移す。条件なしでは強調を消し、0件では表示操作を無効にする。未解放地域は場所を確認できるが、移動ボタンは無効のまま。閲覧専用でも記録・位置・進行を変更しない。

探索の到着処理は従来の一般曲名ではなく、実際の地域BGMと比較する。街道などの専用曲が流れている間、歩くたびに同じ曲の再選択を呼ばない。既存の境界判定、音量・曲自体、歩行速度、保存形式は維持する。

## 検証

- test-world-route-cues.mjs：4サイズで検索結果と強調範囲、地図表示範囲・フォーカス、0件時の無効化、解除、未解放地域の閲覧、閲覧専用の記録非変更、48px操作・表示崩れを確認。
- test-world-polish.mjs：実際の街道曲に落ち着いた後、到着処理から同じ曲を再選択しないことを確認。境界の3歩判定、港への位置変更、拡大・表示移動・経路表示も維持。
- check-field-encounters.mjs：音楽比較に必要なsceneForMapをテスト環境に追加し、既存51地域の遭遇判定を維持。
- 72件の回帰検査・生成物照合、統合後の公開21ファイル一致・公開URLのMAP操作／徒歩・船／保存復元を確認。

スマホはブラウザー模擬検証。実機スマートフォン・イヤホンの聴感確認は未実施。

全国MAPを閉じた後の古い行先操作は受け付けず、別画面を閉じたり移動予定を上書きしたりしない。4サイズで設定画面・記録・予定が維持されることを確認する。
