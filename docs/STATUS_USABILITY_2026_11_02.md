# ステータス画面の改善

### ステータスの回復状況・成長比較と確認動線

共通レベル・次までの経験値と進捗、全員の要回復人数／戦闘不能人数／不足HP・MPを先に表示する。全員／同行／控え／要回復で絞り込み、仲間への移動を開いて直接カードへ移動できる。攻撃力・防御力・会心率・回避率と6つの基礎能力を常時表示し、職業熟練度の現在値・上限・次までのJPを確認できる。職業技の消費MPは、職業特性による軽減後の値を表示する。

成長比較は仲間ごとに現在の職業・装備・熟練度を保った次レベルの12項目を比較する。上限では次レベルを予測しない。HPと基礎能力の体力の違いは開閉できる説明へまとめる。所持金・物語ランクなどの補助情報も開閉できる。

各仲間から成長・装備・習得技へ移動し、戻ると絞り込みとカード／成長の開閉状態を復元する。ステータスの閲覧は保存データを変更せず、現在HP・MPを回復しない。閲覧専用でも絞り込みと確認を使える。古い画面の操作と保存中の操作は拒否する。

## 検証

22職業×3レベルの成長12項目を実際の能力計算と照合する。回復集計、経験値進捗、レベル上限、職業技の消費MP、旧記録で現在値が欠ける場合も確認する。6画面サイズで9人表示、戦闘不能、要回復・空結果、カード移動、成長比較、装備・技との往復、開閉保持、古い操作、閲覧専用と再読込を検査する。関連画面と全回帰・生成物・最新CIを確認し、公開後にファイル一致と操作を再検査する。実機スマートフォンとOSキーボードは未確認。
