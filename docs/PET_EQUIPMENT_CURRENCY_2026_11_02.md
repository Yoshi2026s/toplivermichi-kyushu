# ペット・装備・被ダメージと通貨制度の変更

## 変更

- 北向きの同行ペットは、前向き素材を参照して生成した22種類の専用イラストに変更。最後方を歩く経路、歩行8段階と成長装飾は保持。原画・透過素材・生成条件は assets/illustrated/PET_REAR_SOURCES.json、正規化は scripts/prepare-pet-rear-art.mjs。OpenAI組込image_genを使用。
- チケット制度、交換所と交換操作、海洋敵3体の調査報告を廃止。依頼・実技・宝箱からのチケット付与と、所持数・報酬の表示も削除。カードや道具を受け取る宝箱、物語・ボス・経験値・ゴールド報酬、救助と漂着宝箱は維持。
- ユーザー指定により、ペットのお迎えは旧料金と同額のゴールドへ変更。物語の解放条件・所有ペット・お世話・用品は保持。
- 旧版で入手済みのUX01〜UX06は記念装備として保全し、装備・保管と売却／廃棄不可を維持。新たな交換経路は削除。
- 独立した装備メニューを追加。仲間・武器／防具／アクセサリーを選択し、能力比較後に確定。装備中の他者から渡す場合は両者を明示。確定後は装備メニューへ戻り、保存に失敗した場合は双方の装備を復元。街でのみ変更でき、閲覧専用では比較だけ可能。
- 装備防御と身の守りが弱い敵の攻撃力を上回ると全攻撃が0になっていた経路を修正。通常・ボス・海上の攻撃を再現し、装備だけで無傷固定にならないよう最低1を残す。回避、防護による完全吸収、ガード、痛恨、敗北は保持。オートの予測も同じ敵フェーズを使用。

## 保存と移行

旧セーブと旧バックアップの残高は1対1でゴールドへ一度だけ加算し、旧キーを削除。再読込・再起動・復元で重複しない。新規開始時は200G。新しいセーブは旧通貨キーを持たず、旧キーがないデータも同じ検証を通す。旧結果の通貨項目と旧調査フラグは移行時に除去し、現在の報酬として再付与しない。

金額が不正、または合計が安全な整数の上限を超える場合は、加算・削除せずに移行を拒否。既存ペット・装備・所持品・物語進行は保全。schemaVersionと保存先・URLは変更しない。新形式を古い版で開くことは想定せず、現行版を利用する。

## 検証

通貨移行の一度性・不正金額・上限・ゴールドでのお迎え・廃止イベントの拒否を検査。高防御による無傷の再現、通常／ボス／海上でのHP減少、ガード・防護・敗北・旧戦闘データの有限値を検査。22種類の後ろ姿の描画、成長・8段階歩行・キャッシュ上限を検査。

ブラウザーでは装備の実際の付け替え・保存失敗・閲覧専用・親メニュー復帰と、旧残高を持つ記録の再読込、バックアップ復元後の再読込、MAP同行、戦闘コマンドからのHP減少を6画面条件で確認する。生成物・独立候補・CI・公開ファイルと公開操作を確認する。

ブラウザー模擬検証であり、実機スマートフォン・実際のOSキーボード・読み上げ機器は未検証。検証には新規ブラウザー環境を使用し、利用者の既存データを操作しない。

ローカル確認：装備・旧通貨の移行・再読込・バックアップ復元・保存失敗・閲覧専用・北向き同行・戦闘コマンドでのHP減少が6条件で成功。全36メニュー、閲覧専用の全36メニューと4画面、戦闘結果の正確な金額表示も各6条件で成功。最終版の全体検査後に検証記録と生成物を照合する。
