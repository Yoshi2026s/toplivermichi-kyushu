# 音・表記・操作の改善 第3回（2026-11-01）

PR #62の公開版を基点に、遅延音の状態確認と戦闘操作の表記を改善する。

- 敵を倒した直後の180ms後に鳴る効果音は、同じセーブ・同じ戦闘・戦闘画面が続いている場合だけ再生する。結果・探索・タイトルへの切替、別セーブ・別戦闘、非表示、勝利済みでは古い効果音を鳴らさない。
- 未定義またはプロトタイプ由来の曲名・ジングル名を受け取っても、再生中の曲や予約した場面切替を消さない。定義内の曲名かどうかを状態変更前に確認する。
- 戦闘ドックの「AUTO オート」「AUTO 停止」を「オート／開始」「手動に／戻す」へ変更。読み上げは「オート戦闘を開始」「オート戦闘を中断して手動に戻す」とし、タップ後に何が起こるかを明示する。
- 波形検査は左右両チャンネルの振幅・有限値・消音・復帰を確認し、検証用WAVもステレオへ変更。CIの検証成果物に波形JSON・WAVと音量設定の画像・JSONを含める。

曲・素材・保存キーや形式、戦闘の計算・報酬・移動の仕様は変更しない。既存の音量補間・残響の調整・連打抑制を維持する。

## 検証方法

- 修正前に、画面切替後の撃破音と、未定義曲による現在曲の変更を回帰検査で再現して失敗を確認する。修正後は正常な再生と旧状態の拒否を検査する。
- 実ブラウザーのOfflineAudioContextでタイトル・地上・戦闘を各5秒描画し、左右の波形を確認する。
- 6サイズで戦闘オートの開始・中断とラベル・選択状態・横溢れなしを確認。既存のメニュー・装備・道具・人物・戦闘の検査も継続する。

ブラウザー模擬・波形の自動検査による確認。実際の試聴・物理スマホやイヤホンの音質確認とは区別し、利用者の既存保存データは使わない。
