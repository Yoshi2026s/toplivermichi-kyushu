# ホーム画面アイコン

剣・王冠・緑の宝石のオリジナル画像を画像生成で制作。公式ブランドロゴや文字は使わず、小さなホームアイコンでも識別しやすくした。
生成指示：濃紺・緑の背景、銀の剣、金の王冠、緑の宝石、正方形、不透明、文字なし。編集元は assets/icons/quest-icon-source.png、各サイズはLanczos縮小。

iOS: apple-touch-icon 180px。Android: manifest.webmanifest の192px/512px。ブラウザーのfaviconも192pxに設定。画像とmanifestには更新用クエリを付与。保存キー・ゲーム処理は変更なし。

検証：既存回帰85件のうち84件成功。追加ファイルを埋込素材として扱ったことによるリリース検査失敗は、配信ファイル一覧へ分類を修正して再検査成功。追加のホームアイコン検査成功、build --check成功。GitHub CIで全検査を再実行する。
ローカルのスマホ模擬検証はChromium起動時のOSソケット権限制限で4画面とも未実行。物理iPhone/Androidのホーム追加は未確認。

既存ホームアイコンはOSのキャッシュで旧表示が残る場合がある。公開ページから新しく「ホーム画面に追加」して確認する。保存データを保全するため、既存のWebアプリを削除する手順は案内しない。
