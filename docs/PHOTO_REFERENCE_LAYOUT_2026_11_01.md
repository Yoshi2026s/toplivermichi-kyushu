# 添付写真を参考にした画面配置（2026-11-01）

## 対象

写真1の戦闘画面、写真2の装備画面、写真3〜5のオート移動・やる事画面を参考にした。画像そのものの公開やゲーム素材の置き換えは行わず、現行の絵・戦闘計算・保存キー・保存形式を維持する。

## 反映

- 戦闘: 敵データを上部の2列カードへ分離し、敵の画像と背景、前後に読める進行文、味方パーティー、同行ペットの順で表示。HP/MPを2行と小さなゲージで表示。ペットの支援詳細は戦闘記録の中へ整理。
- 進行文: 前後移動・全文表示。閲覧中の古い文は新着で追い出さず、最新を見ているときは新着へ追従。80件上限・戦闘変更・空のログにも対応。閲覧状態はG内だけで、保存データを変更しない。
- 装備: 仲間の前後切替、最大HP・最大MP・攻撃力・防御力の4枚の数値カード、3部位の切替を追加。比較・付け替えは既存の確認手順を維持する。
- 各メニュー: 金色の枠、固定見出しとMAPへ・戻る、本文の縦スクロール、分類→説明→検索→一覧の順へ統一。行先は区切り線のある縦一覧。施設の近道は一覧の後へ配置し、行先を先に読めるようにする。
- 下部操作: 写真に合わせ左が戻る、中央がメニュー、右がスティック・決定。戦闘時は解説・戦闘記録・AUTOも配置。説明・README・仕様書も位置を合わせる。
- 低い画面: 情報を極端に縮小せずスクロールを使用。行動・対象を選んだ時は、確定操作が固定パネルに隠れない位置へ必要な分だけ移動する。ログを読むだけでは戦闘状態も選択も変えない。

## 検証

- 新規単体検査: 進行文の純粋な閲覧、HTMLエスケープ、境界、別画面・会話中の拒否、新着追従と履歴保持、80件の切詰め、別戦闘・空状態。
- 新規ブラウザー検査: 6サイズでメニュー6画面と装備、見出し固定、戻る/決定の配置、4人・2匹・敵2体の順序、長い敵名、ログ全文、実際の攻撃、AUTO開始/停止。
- 旧検査の変更: 戻る位置を写真の左へ変更したことを検査。戦闘の情報順が変わり、低い画面ではスクロールで操作へ到達する設計に合わせ、到達後の確定ボタンが固定パネルより上にあることを検査。48pxの主要操作・画像の大きさ・文字のはみ出し・実行可能性の検査は維持。
- ブラウザーのタッチ模擬。物理スマホとOSキーボードは未確認。

## 実行結果

全体回帰60/60、生成物一致・構文検査成功。写真参考の新規UI検査は6サイズすべて成功。戦闘の可読性・実行操作は4サイズ、既存の移動案内・入力解放・閲覧専用とペット購入・育成・保存復元は小画面で再確認した。CIでは新規検査も含めた全モバイル検査を実行する。
