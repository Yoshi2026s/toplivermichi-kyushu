# ポコチャクエスト

**全国編：v5.34（2026年10月30日）**

全国47都道府県・51拠点に、固有ストーリーと地域ボスを収録しました。福岡から北海道まで全51本の本編依頼を進め、全国編エンディングへ到達できます。追加43地域の物語は本作の新規創作です。

男女混合アイドルグループを脱退したヒロインと旅立ち、トップライバーを目指す、スマートフォン向けの創作RPGです。街で依頼を受け、街の出口から街外MAPへ進みます。街と室内では敵に遭遇せず、通常戦闘とボス戦は街外のみで発生します。

ペット22種・10段階育成、65海域と3,250海洋敵、全100バッジ、5能力・22職業特性、33職歴・66記念装備、追加技・継承技・必殺技、状況別リスナーコメント、全47地域支援を収録しています。

移動メニューの「街外へ」で街の出口まで歩けます。街間は街外MAPの道を通り、隣の街外から街へ入ります。訪問済みの街への直行には、各街の新幹線駅を利用します。地図からの直接移動はできません。
