# v5.34 能力・職業・職歴装備の実装仕様

以前の指示書にある機能要件を現行v5.33へ統合した。参照元の私用v5.36の能力表・旋律・装備表の完全な原データは入手できていないため、下記の能力式、職業特性の数値、職歴品と追加技の名前・性能は本版の新規設計である。参照元の計算式や375技を完全再現したという意味ではない。既存の経験値・熟練度・所持品・装備・物語を初期化しない。

## 5能力と戦闘計算

Lは総合レベル、Rは現在職の熟練度、Vは `1+floor((L−1)/20)`。職業ごとの倍率を `m0〜m4` とし、装備の対応能力を最後に加える。

| 能力 | 装備加算前の式 | 反映先 |
| --- | --- | --- |
| 体力 | `floor((25+3×(L−1)+floor(R/2))×m0)` | 最大HPの職業倍率。装備の体力は1につき最大HP＋2 |
| ちから | `floor((10+2×(L−1)+floor(R/3))×m1)` | 6につき攻撃の追加値＋1 |
| 身の守り | `floor((8+L−1+floor(R/3))×m2)` | 6につき通常被ダメージ−1 |
| すばやさ | `floor((8+L−1+floor(R/4))×m3)` | 会心率・回避率 |
| 魅力 | `floor((10+floor((L−1)×0.8)+floor(R/3))×m4)` | 応援とエールが増える技能で20につきエール＋1 |

通常攻撃の基礎値は `10+2L+V×(武器攻撃+装飾攻撃+floor(ちから/6)+職業の単体追加値)`。技能追加値、コメント連携、ペット強化を同じ成長係数で加え、敵の防御を引く。ステータスの攻撃力もこの通常攻撃の基礎値を表示する。

通常の被ダメージは攻撃威力から `V×(防具+防護)+floor(身の守り/6)` を引き、職業の軽減を適用し、ガード中は半減する。最大HPは従来のHP式を職業倍率m0で補正し、装備の体力×2を加える。MP上限は従来の式（基礎8、熟練度・装備加算、上限10）を使用し、戦闘・道具・ペット・保存で同じ上限を参照する。

会心率は `min(30%,3%+すばやさ/1800+職業補正)`、回避率は `min(25%,2%+すばやさ/2000+職業補正)`。会心は実際に引いた敵防御分を戻して1.5倍。痛恨は防具・身の守り・防護・職業軽減を無視して1.5倍、ガードの半減は残る。通常の敵の回避率は2%、痛恨率は3%。

各戦闘の乱数状態・使用回数を保存し、抽選は有効な行動の確定後だけ行う。プレビューとオートAIの候補比較は乱数状態を変更せず、未来の会心・回避を見ない。保存再開で同じ戦闘の抽選列を引き直さない。

## 職歴・ヒロイン・技能

- 職歴33種はCR01〜CR33。各職歴にHW01〜HW33、HA01〜HA33の武器・防具、計66点を用意。新規開始時に選んだ2点を取得・装備し、既存セーブへは重複配布しない。職歴はプロフィールであり、職業の変更とは別。
- 主人公とヒロインは全角1〜12文字、男女から設定できる。正規化した同名は拒否する。旧セーブの固定人物IDと物語進行は維持し、表示名だけ保存設定を参照する。
- 22職の本来の技は熟練度3で継承。現在職以外の習得済み職業技を転職後も使用できる。
- 追加技は66件（22職×3段階）。必要条件はLv5・熟練度2、Lv12・熟練度3、Lv25・熟練度5。習得後は転職しても保持する。
- 9人それぞれに固有必殺技。Lv5・戦闘3ターン目からMP4・エール50、1戦闘1回。通常の追加・継承技とは別に記録する。
- 職業技は再使用1ターン、継承技は2ターン、追加技は各1〜3ターン。技能一覧にMP・条件・再使用までの残りターンを表示する。検索・ページ・対象選択・最後の確定を分ける。

## ハローワーク・実技・バッジ

街の実在するハローワークのそばで、22職それぞれの3段階・各3択の固有体験に参加できる。全66問は別の問いで、誤答は助言を出して同じ段階へ戻る。正しい3判断で転職先がパーティー共通で解放される。料金、レベル条件、繰り返しの金銭報酬は設けない。

進行中の体験・正解済み段階は保存され、別の街でも続行できる。転職は物理的な施設への近接、現在画面、操作可能状態、職業イベント完了、在庫容量を確定時に再検査する。現在職を続けるために過去のイベントクリアを捏造しない。閲覧専用、戦闘中、施設外、保存中、古い確認は状態を変更しない。保存失敗時は変更を戻す。

街外の「実技チャレンジ」は22職を選べる10ターン制の戦闘。街では開始できない。全戦闘でオート使用可。5ターン以内の勝利でB009、実技勝利でB093、実際の会心でB017、実際の回避でB035、必殺技使用でB099、追加・継承技使用でB100を記録し、勝利結果で確定する。ペット10種の判定は `src/pets.js` と共に全100種のバッジへ統合する。
