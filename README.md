# ポコチャクエスト｜トップライバーへの道 九州編

**公開版：v5.29（2026年10月22日の確認済みZIPから再配置）**

ドラフトPRのプレビューは v5.29-dev。福岡編に加え、佐賀県唐津市の主編M03・探索3区域・地域ボス・配信まで実装中です。佐賀市の探索拠点と3区域まで実装中です。佐賀市の主編依頼・地域ボス・配信は未収録です。
